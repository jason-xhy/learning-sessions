# 湖南省小学二年级 语数外 自学包

面向湖南家庭的二年级（2026~2027 学年）语文·数学·英语自检与陪学材料：以《义务教育课程标准（2022年版）》第一学段（语文/数学）与一级（英语）为锚。同家族年级包：三年级 `hunan-g3-learn` / 四年级 `hunan-g4-learn` / 初一 `hunan-g7-learn`。

## 当前交付：month1-selfcheck（上学期第一个月自测）

三科 × 三版自包含 HTML（家庭只拿 `html/`，双击即用）：

| 文件 | 用途 |
|---|---|
| `month1-selfcheck/html/2026-2027上学期第一个月{科目}自测.html` | **学生交互卷（家庭直发用这个）**：点选作答、计时、交卷自动批改、主观题对照采分点自评、家长复核改判、未讲到可跳过按已做题折算、短板清单与成绩单摘要 |
| `month1-selfcheck/html/…{科目}自测-家长版.html` | 家长批改用：全文 + 逐题查分卡 |
| `month1-selfcheck/html/…{科目}自测-教师版.html` | 教师备查：全文 + 双向细目表 + 知识框架图 |
| `month1-selfcheck/en/g2-{chinese\|math\|english}.html` | 微信直发 ASCII 链接（学生版字节等同副本） |
| `month1-selfcheck/{科目}-{教师\|学生\|家长}版.md` | 打印与单源（学生/家长版由教师版生成，禁手写） |
| `month1-selfcheck/_规范.md` | 结构契约与机检清单 |

## 教材口径

语文统编版（全国统一）；数学人教版；**英语外研版（一年级起点）**。单元对照写在本卷教师版"本月学什么"，进度差异（学校快慢）由卷内"进度差异说明"给跳过题号并按已做题折算，不锁教材页码。

## 注意

- 遵守**双减**：一次一科、不连考；二年级写话与阅读可分开完成（相隔半天内）。
- 每份文件页脚带 AI 辅助生成标识；使用前请家长/教师抽查核对。
- 本包以 [MIT](LICENSE) 开源；生成与机检工具不在本公开仓，随私有仓 learning-sessions-plan 的 `tools/learning-sessions/hunan-g2-learn/` 分发（本仓为纯交付物仓）。

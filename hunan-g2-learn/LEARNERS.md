# 学习者指南 · 二年级月度自测怎么用

> 写给家长。二年级孩子识字量与读题速度有限，请按下面的节奏陪一次，一次只测一科。

## 发哪份、怎么发

- **微信直发**：发 `month1-selfcheck/en/` 下的链接（`g2-chinese.html` / `g2-math.html` / `g2-english.html`，纯英文文件名，微信里点开可靠；内容与学生版逐字节相同）。
- **本机/打印**：双击 `month1-selfcheck/html/2026-2027上学期第一个月{科目}自测.html`（学生交互卷，可打印，打印态自动隐藏按钮）；家长批改配合 `-家长版.html`（逐题查分卡）；教师备查用 `-教师版.html`。
- **打开兜底**：优先用手机/电脑浏览器（Chrome、Safari）打开；若微信内置浏览器交互异常，点右上角"在浏览器打开"。成绩出来后让孩子把**成绩单摘要**截图回传。

## 一次完整的自检（约 40 分钟/科）

1. **准备（10 分钟）**：安静桌面，掐表计时；告诉孩子"错了不丢人，找出短板才是目的"。一次只测一科、不连考（双减红线）。
2. **作答**：选择/判断在页面上点选；填空、口算、笔算、写话在纸上写，回到页面对照参考答案**按采分点给分**——宁可少给、不高估。没讲到的题勾"未讲到，跳过"，等级自动按已做题折算。
3. **复核**：孩子自批后，家长抽 3 题复核；不一致以家长为准，可在页面上"改判"。
4. **解读**：≥85 优 / 70~84 良 / 60~69 合格 / <60 待加强。第一个月的分数≠能力，重点是页面上自动汇总的**知识点短板清单**（最需补 ≤2 个）。
5. **回炉**：按短板清单回课本对应单元；7~10 天后只重做错题，不整卷重测。

## 纸面测不到的能力（口头小测）

- **语文朗读**：让孩子选一段本单元课文读给你听，只反馈"哪里听得最舒服"，不逐字纠音。
- **数学量感**：让孩子估一估"数学书有多长（厘米）、教室有多高（米）"，再用尺子对一对。
- **英语听力**：家长读 5 个本月学过的词或指令（按教师版"本月学什么"选词），孩子做动作或指认，记下对了几个。

## 维护说明（会话 agent 执行）

md 是唯一源：学生/家长版由 `build_versions.py` 生成、`html/` 由 `build_html.py` 生成，均**禁手写**；`en/` 副本由映射从 `html/` 复制（`make_en_aliases.sh`）。改动后必跑四件套（`build_html.py` 重建 + `check.py` / `check_html.py` / `test_html_score.js`，工具在私仓 `tools/learning-sessions/hunan-g2-learn/month1-selfcheck/`）；结构契约见 `month1-selfcheck/_规范.md`。

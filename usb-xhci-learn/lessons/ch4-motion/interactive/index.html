xHCI 第 4 章交互教学台

TRB（传输请求块，Transfer Request Block）在三方之间流转：xHCI 驱动 写环敲门铃 → xHC 控制器 取指执行、产生事件 → 驱动读事件环收回执。判据：xHCI 1.2b §4.1（p68）、§4.3（p71-80），字段值逐条对表 evidence/ 切片与 EVIDENCE.md。示例设备：FS 设备 · Slot ID=1（由 xHC 自选，§4.3.2 p75）。零依赖单文件，双击即开。

剧本：Enable Slot 命令闭环

设备插上根端口、端口复位完成后，软件要先拿到 Device Slot——「The Enable Slot Command returns a Slot ID that is selected by the host controller.」（§4.3.2 p75）

  1. ○① 写命令 TRB 上环 驱动面板：环选「命令环」· 类型选「Enable Slot」→ 点「写 TRB 上环」
  2. ○② 敲门铃 DB Target=0 点「敲门铃」→ 选「DB Target = 0 · Host Controller Command」（写门铃寄存器 0）
  3. ○③ xHC 执行 点金色「执行」：命令环 deq 推进（取指），完成事件写上事件环（enq 推进）
  4. ○④ 确认完成事件 点事件环上出现的「Command Completion Event」卡，查看内容（Slot ID=1）
  5. ○⑤ 驱动读事件环 点「读事件环」：事件环 deq 推进，回执收入回执栏——闭环完成
✓ 剧本完成：Enable Slot 命令闭环（写 TRB → 门铃 0 → 执行 → 完成事件 → 读事件）

回执栏（读走的完成事件）

    场景：FS 设备 · GET_DESCRIPTOR（Device Descriptor 前 8 字节）

    「For FS devices, system software should initially read the first 8 bytes of the USB Device Descriptor to retrieve the value of the bMaxPacketSize0 field」（§4.3 p72 步7）——LS/HS/SS 设备（8/64/512 字节）可跳过此步。

    「The USB GET_DESCRIPTOR request requires a Data Stage, so the Setup Stage TD shall be followed by a Data Stage TD, then a Status Stage TD.」（§4.3 p73 a）——控制传输三段：Setup → Data → Status；本例每段 TD 恰好一个 TRB（a single Setup/Data/Status Stage TRB，§4.3 p73 ii/iv/vi）。

    第 1 步 · URB（内核侧请求单位）

    字段值含义
    bmRequestType80hDir=Device-to-Host · Type=Standard · Recipient=Device（§4.3 p73 ii）
    bRequest6GET_DESCRIPTOR（§4.3 p73 ii）
    wValue0100hLow byte=0（Descriptor Index）· High Byte=1（Descriptor type）（§4.3 p73 ii）
    wIndex0（§4.3 p73 ii）
    wLength8只读前 8 字节（§4.3 p72 步7 / p73 ii）
    缓冲8B 接收缓冲Allocate an 8 byte buffer to receive the Device Descriptor（§4.3 p73 i）

    URB 是内核侧的请求单位，xHC 不认识 URB——必须拆成 TRB（传输请求块）放上 EP0 传输环。下面把这一个 URB 拆成三个 TRB。

    第 2 步 · 拆成 TRB（三个 TRB 槽 · 每格下拉选值，对/错即时判定并给规范依据）

    Setup Stage TRB 0/9

    Data Stage TRB 0/6

    Status Stage TRB 0/6

    把每个 TRB 的字段填对（填对变绿、填错变红并给一句规范依据）。三个槽全绿后，第 3 步的 TRB 卡解锁。

    第 3 步 · TD 上环（点选 TRB 卡 → 点 EP0 环格子放入）

    Setup Stage TRB
    Data Stage TRB
    Status Stage TRB

    每放一段，驱动推进 EP0 传输环 Enqueue Pointer（Advance the Endpoint 0 Transfer Ring Enqueue Pointer，§4.3 p73 iii/v/vii）。三段全部就位后才能敲门铃。

    设备（USB device）· FS · EP0 MPS=8（§4.3.3 p76）
    GET_DESCRIPTOR · IN · 8 bytes
    Data Stage：DIR=1，设备→主机（§4.3 p73 iv）
    驱动 · Device Descriptor 接收缓冲（8B，§4.3 p73 i）

      后续：wMaxPacketSize=8 与 EP0 当前 MPS（FS 默认 8）一致则无需更新；若不同，驱动更新 EP0 Context Max Packet Size 并发 Evaluate Context Command（A1=1）告知 xHC（§4.3 p74 ix/x）。

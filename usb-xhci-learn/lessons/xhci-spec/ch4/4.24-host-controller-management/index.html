xHCI 1.2b §4.24 Host Controller Management · p327–331 · HSE 详见 §4.10.2.6

规范要义

主机控制器管理管两件事：内部错误（4.24.1）与端口到连接器的映射（4.24.2）。前者是 xHC 自身故障的处理协议——HCE 置 1 后 xHC 停止一切活动，软件的响应是 HCRST 复位并重新初始化；后者保证「用户插的口」和「软件看到的根集线器端口」之间的对应关系可管理、可描述。

错误分两路上报：HCE 只报「只影响 xHC 自身」的内部错误（例：访问内部数据结构的 SRAM 奇偶错）；影响整个系统的错误走 HSE（Host System Error，§4.10.2.6）。硬错误会在重新初始化后立刻再次置 HCE——软件要有启发式判断，别让 xHC 永远陷在「错误-复位-初始化」循环里，要报告给用户。

原文对照

“When the HCE flag is set to ‘1’ the xHC shall cease all activity. Software response to the assertion of HCE is to reset the xHC (HCRST = ‘1’) and reinitialize it.”
HCE=1 即全面停车；软件的处置只有一个：HCRST 复位重来。
xHCI 1.2b §4.24.1 p327
“However a hard error shall cause the xHC to reassert HCE immediately after it is reinitialized.”
硬错误的判据：重新初始化后 HCE 立刻再亮——这种循环要被软件打断并上报。
xHCI 1.2b §4.24.1 p327
“There shall be a 1:1 mapping between xHC Root Hub ports and xHC External Ports, where the Root Hub port 1 shall map to External Port 1, Root Hub port 2 shall map to External Port 2, and so on.”
无集成集线器时：根集线器端口与外部端口一一对应，编号从 1 对齐。
xHCI 1.2b §4.24.2.1 p328
“External Ports 1 and n+1 shall map to USB connector 1 to form a USB3 compatible port”
默认映射：USB2 第 1 口与 USB3 第 1 口合体为 1 号连接器——一只 USB3 口背后是两套协议端口。
xHCI 1.2b §4.24.2.2 p329

4.24.2 端口到连接器映射：三形态与默认规则

形态规则要点页
无集成集线器
（IHI=0）		根集线器端口 ↔ 外部端口 1:1，编号对齐（引文③）；协议一致（§7.2 Supported Protocol Capabilities）p328
有集成集线器
（IHI=1，USB2 侧）		根端口与外部端口间至多一层集成集线器；USB2/Enhanced SS 层级错位只允许「USB2 在 Tier 2、USB3 在 Tier 1」一种；同协议外部端口连续编号（1..n=USB2，n+1..n+m=USB3）；厂商必须提供映射描述（Appendix D 的 ACPI 例）p327–328
嵌入式集线器
（系统侧）		外部端口到连接器不允许层级错位；系统必须经 ACPI 等提供五级映射描述（根端口/集成集线器/外部端口/嵌入式集线器/连接器）p329
无描述时的默认映射外部端口 1 与 n+1 → 连接器 1（USB3 兼容口），2 与 n+2 → 连接器 2……（引文④）；多出的归 USB2 或 USB3 兼容口p329

USB3 集线器=USB2 集线器与 Enhanced SuperSpeed 集线器的逻辑合体，各自独立总线运行（p328）。

xHCI 1.2b §4.17 Interrupters · p261–269 · 节流寄存器 §5.5.2

规范要义

中断器（Interrupter）管理事件与它们对宿主的通知：xHCI 支持最多 1024 个（HCSPARAMS1 的 MaxIntrs 定实现数，至少 1 个）。每个中断器 = 1 个中断器管理寄存器（IMAN）+ 1 个节流寄存器（IMOD）+ 1 条事件环，并且必须映射到单个 MSI 或 MSI-X 中断向量。总开关是 USBCMD 的 INTE 位。

节流（§4.17.2）：中断要同时满足三条件——节流计数 IMODC 减到 0、Interrupt Pending Enable（IPE）=1、事件处理器不忙（EHB=0）。重负载时中断被合并（IMODI 默认 4000≈1ms，建议范围 651–5580）；轻负载时计数停在 0、事件一来立即中断（Figure 4-22/4-23/4-24）。

事件进哪个中断器由 Interrupter Target 字段决定（Transfer TRB 或 Slot Context，§4.17.1/§4.17.4）；不支持映射时该字段被忽略、全部进中断器 0。注意：规范不保证跨事件环的事件顺序。

📎 §4.17 中断器=管理与通知单位（p261）

xHCI 1.2b §4.17 · p261

An Interrupter manages events and their notification to the host. The xHCI supports up to 1024 Interrupters.

本链消费的就是中断器 0 的事件环——MSI-X 通知到达后，软件把环上的事件逐条取走。

📎 §4.17 每中断器单向量（p261）

xHCI 1.2b §4.17 · p261

Each Interrupter shall be mapped to a single MSI or MSI-X interrupt vector.

中断器与 MSI-X 向量一一绑定——向量 0 的到达即中断器 0 有事，软件无需再猜是哪个环。

📎 §4.17.2 MSI/MSI-X 的 IP 自动清（p265）

xHCI 1.2b §4.17.2 · p265

If PCI Message Signaled Interrupts (MSI or MSI-X) are enabled, then the assertion of the Interrupt Pending (IP) flag in Figure 4-22 generates a PCI Dword write. The IP flag is automatically cleared by the completion of the PCI write.

MSI/MSI-X 形态 IP 由 PCI 写完成自动清——代码形态＝ip_autoclear 为真时跳过软件写。

📎 §4.17.2 INTx# 才软件清 IP（p265）

xHCI 1.2b §4.17.2 · p265

If the PCI Interrupt Pin mechanism is enabled, then the assertion of Interrupt Pending (IP) asserts the appropriate PCI INTx# pin. And the IP flag is cleared by software writing the IMAN register.

引脚中断形态才需要软件写 IMAN 清 IP——xhci_clear_interrupt_pending 软件写 1 分支服务的就是这条。

📎 §4.9.4 ERDP 写回是软件义务（p163）

xHCI 1.2b §4.9.4 · p163

System software shall advance the Event Ring Dequeue Pointer by writing the address of the last processed Event TRB to the Event Ring Dequeue Pointer (ERDP) register.

消费进度必须写回 ERDP——不写回，xHC 会认为事件仍未被处理（EHB 保持 1，不再发新中断）。

📎 §4.9.4 禁止连续写同值（p165）

xHCI 1.2b §4.9.4 · p165

Software writes to the ERDP register shall always advance the Event Ring Dequeue Pointer value, that is, software shall not write the same value to the ERDP register on two consecutive write operations.

连续两次写同值被规范禁止——内核对策＝指针未动且不清 EHB 时干脆不写（:3060）。

📎 §5.5.2.3.3 EHB 写 1 清（RW1C）（p393）

xHCI 1.2b §5.5.2.3.3 · p393

Event Handler Busy (EHB) - RW1C. Default = ‘0’. This flag shall be set to ‘1’ when the IP bit is set to ‘1’ and cleared to ‘0’ by software when the Dequeue Pointer register is written.

IP 置 1 时 EHB 同置（节流三条件第三条「事件处理器不忙」）；软件写 ERDP 即清 EHB——RW1C＝写 1 清。

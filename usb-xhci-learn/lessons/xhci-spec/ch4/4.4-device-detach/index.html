xHCI 1.2b §4.4 Device Detach · p81 · Disable Slot 命令语义 §4.6.4 p96

规范要义

设备从根集线器端口拔出时，xHC 的端口硬件先于软件知道：PORTSC 的 CCS（当前连接状态）清 0、CSC（连接状态变化）置 1。状态变化不是事件本身——PSCEG 发生 0→1 跳变才产生端口状态变化事件（§4.19.2），事件走事件环送达软件。

软件确认拔出后，必须用 Disable Slot 命令停用该端口关联的设备槽。命令的投递沿用 §4.1 命令模型：命令 TRB 上唯一的命令环 + 写门铃 0；命令完成事件必回（§4.6.4）。

Disable Slot 由 xHC 执行五项回收（禁槽门铃、回收周期端点带宽、终止该槽 USB 活动、释放内部资源、把槽标记为可复用）；软件随后释放自己的数据结构（Device Context、传输环内存等）。拔出后设备侧无任何响应——本节全部动作发生在主机侧。

📎 §4.4 拔出由端口硬件捕获（p81）

xHCI 1.2b §4.4 · p81

When the device is detached from a Root Hub port, the PORTSC Current Connection Status (CCS) bit shall be cleared to ‘0’ and the Connect Status Change (CSC) bit shall be set to ‘1’.

拔出先落在寄存器位上（CCS=0/CSC=1）；PSCEG 0→1 跳变才有 Port Status Change Event（§4.19.2）——事件投递在链外，本链从软件确认拔出之后接手。

📎 §4.4 确认拔出后必须 Disable Slot（p81）

xHCI 1.2b §4.4 · p81

After the detection of a detach, system software shall disable the Device Slot associated with the port by issuing a Disable Slot Command for the affected slot.

停用槽位是软件的义务——本链投递的就是这条命令。

📎 §4.6.4 xHC 五项回收（p96）

xHCI 1.2b §4.6.4 · p96

When a Disable Slot Command is processed by the xHC it shall:

五项全部由 xHC 完成：禁槽门铃、回收周期端点带宽、终止该槽 USB 活动、释放内部资源、槽标记为可复用。

📎 §4.6.4 前置条件（p96）

xHCI 1.2b §4.6.4 · p96

Any active endpoints associated with the slot shall be in the Stopped state or Idle in the Running state, and any outstanding Transfer Events shall have been received.

发 Disable Slot 前该槽端点须 Stopped（或 Running 且 Idle）、未决 Transfer Events 已收齐——否则行为未定义。

📎 §4.6.4 软件侧可释放内存（p96）

xHCI 1.2b §4.6.4 · p96

software can free the Device Context, Transfer Ring, Stream Context Array, etc. data structures associated with the slot.

xHC 把槽标记可复用后 DCBAA 表项不再被视为有效——软件可安全释放 Device Context、传输环、流上下文数组等内存；对应本链 :889-891（传输环）与 :914-917（上下文）两处释放。

📎 §4.1 只有一条命令环（p68）

xHCI 1.2b §4.1 · p68

There is only one Command Ring that is used for issuing xHC specific commands or commands related to Device Slots.

命令环是全 xHC 单例——Enable Slot 取槽与 Disable Slot 还槽共用同一条环（§4.1 走读卡的镜像链）。规范 p68 此处印作「xHC specific」。

📎 §4.1 命令门铃（p68）

xHCI 1.2b §4.1 · p68

All xHC commands are issued by placing the desired Command TRB(s) (Section 6.4.3 Command TRBs) on the Command Ring, then ringing the xHC command Doorbell register, that is, writing the Host Controller Command code to the DB Target field of Doorbell register 0

投递动作＝写环＋写门铃 0，缺一不可。

📎 §4.6.4 必回完成事件（p96）

xHCI 1.2b §4.6.4 · p96

A Command Completion Event is always returned for a Disable Slot Command.

Disable Slot 必回一条命令完成事件——命令模型的闭环对回收路径同样成立，回执走事件环。

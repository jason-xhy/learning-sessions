xHCI 1.2b §4.5 Device Slot Management · p81–90 · 状态图对照 Figure 4-2 p85 · 请求映射 §4.5.4 p89–90

规范要义

每台挂在 xHC 上的 USB 设备占用一个设备槽（Device Slot）；xHCI 最多支持 255 台——不是 256，架构保留了一部分槽位挪作他用（脚注 11：虚拟化场景下分给某个 VF 的槽，对其它 VF 就显示为保留，p81）。一个槽由三件套组成：DCBAA 表项（64-bit 指针，指向该槽 Device Context 的基地址）、Device Context 数据结构、Doorbell Array 里的槽门铃寄存器。Slot ID 是访问三件套的统一索引：软件（规范原文称 system software，系统软件）拿它查 DCBAA 取回上下文指针，也拿它选中该槽的门铃寄存器。

Device Context 是 32 个 context 的数组（Figure 4-1，p82）：DCI 0 = Slot Context（管整台设备与全部端点共享的属性），DCI 1–31 = Endpoint Context——DCI 1 恒为 Default Control Endpoint（EP0），其余按 §4.5.1 公式编（Control 端点=端点号×2+1；Isoch/Interrupt/Bulk OUT=×2、IN=×2+1）。内存里从 000h 起每项 20h 连续排布，3E0h（DCI 31）之后 400h 到页尾保留。软件分配 Device Context 时把所有字段清 ‘0’；往输入 Slot Context 里填字段则按命令各有一份例外清单（§4.5.2）：Address Device 要填 Route String、Root Hub Port Number、Context Entries=‘1’ 等，其中 Route String 与 Root Hub Port Number 只认第一次 Address Device，此后其它命令不得改（p84 Note）。

槽状态是本节的主轴：Slot State 五态 Disabled / Enabled / Default / Addressed / Configured，迁移一律由命令的成功完成驱动——命令失败不迁移（p85 Note）。三个易踩的暗桩：① Enabled 是 xHC 内部的逻辑态，Slot Context 的 Slot State 字段没有它的编码——字段值 ‘0’ 同时承载 Disabled 与 Enabled（p87 Note · Table 4-1）；② 同一时刻只允许一个槽处于 Default 态，否则行为未定义（p85/p87 Note）；③ 门铃解锁跟状态走：Disabled/Enabled 态门铃不可写（p86–87），Default/Addressed 态只为 Control EP0 开，Configured 态才对全部已启用端点开（p87–88）。

§4.5.1–4.5.2 Device Context 布局、DCI 编号与输入 Slot Context 初始化

Device Context 内存布局（Figure 4-1，p82）：DCI 0 的 Slot Context 在 000h，之后每个 context 占 20h——DCI 30/31（EP15 OUT/IN）落在 3C0h/3E0h，400h 到 Page Size-1 保留。Endpoint Context 0 恒为设备的 Default Control Endpoint（p82）；某配置下哪些 Endpoint Context「enabled」由 Class Driver 选定的 Configuration 决定（p82，脚注 12：不在 Disabled 态即算 enabled）。

输入 Slot Context 初始化例外清单（§4.5.2 p83–84，默认全 ‘0’ 只填例外）：Address Device——Route String、Root Hub Port Number（拓扑定）、Context Entries=‘1’、Interrupter Target、Speed（由所挂下游端口定）；LS/FS 设备经 HS hub 访问时另填 MTT / Parent Port Number / Parent Hub Slot ID（p83）。Evaluate Context——Max Exit Latency、Interrupter Target（p84）。Configure Endpoint——Context Entries=最大 DCI+1；hub 设备另填 Hub / Number of Ports / TTT / MTT（p84）。Route String 与 Root Hub Port Number 由第一次 Address Device 定值，此后其它命令不得修改（p84 Note）。

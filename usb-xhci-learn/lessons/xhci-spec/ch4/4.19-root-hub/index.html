xHCI 1.2b §4.19 Root Hub · p272–303 · 状态机对照 Figure 4-25 p273（USB2）/ Figure 4-27 p278（USB3）· 事件生成 §4.19.2 p291–293

规范要义

根集线器（Root Hub）不是一颗真的 hub 芯片：xHC 在内部为「每个物理连接器 × 每种协议」各给一套端口寄存器来模拟 hub 行为——USB2（LS/FS/HS）与 USB3（Enhanced SuperSpeed）两种连接类型的 PORTSC 数量可以不等，由 xHCI Supported Protocol Extended Capability（§7.2）声明归属（§4.19.7 p300）。端口状态机的记法是三行一组：状态名 + Port Link State（PLS）+ 信号态，信号态四元组 = PP, CCS, PED, PR（如 1,1,1,0 表示 PP/CCS/PED=1、PR=0，p272）；进入某态时信号态被强制成该态定义值，所以图上不画改这些位的动作（p272 Note）。规范明确两件事：图只示意进出条件，各态的文字定义才是权威（p273 Note）；状态机只引用 PLC 这一个 change bit，其余六个的置位规则归 §4.19.2（p273）。两台状态机的初始态都是 Disconnected（p273/p278）。以下软件侧按规范原文称 system software（系统软件）。

同一副骨架，两族语义在三处岔开。Disabled 含义不同：USB2 的 Disabled 是连接已检出、等待复位的态（PLS=Polling · 1,1,0,0），USB3 的 Disabled 是软件写 PED='1' 得到的链路禁用态（PLS=Disabled · 1,0,0,0）——同名两义，读到 PORTSC 值时先看协议族。Enabled 到达方式不同：USB2 只有端口复位一条路（Disabled→Reset→完成自动迁入，PED/PRC='1'，p274）且复位永不失败（p299 Note）；USB3 在 attach 后由链路训练+配置成功自动迁入 Enabled·U0（p279/p281），其复位（PR/WPR/HCRST）反而可能失败退回 Disconnected（p283）。挂起/恢复路径不同：两族都把 U0（活动）与 U3（挂起）作为 Enabled 子态，挂起同写 Wr(PLS=U3+LWS='1')；恢复时 USB2 主机要写两段（先 PLS=Resume、Resume 时长由软件计时，再 PLS=U0），USB3 主机一段写 PLS=U0 走 LFPS 握手，且设备不许拒绝主机的恢复（p290）。电源域是公共底座：Wr(PP='0') 或过流把任一态打进 Powered-off（大泡，p272 原注）。

事件面是本节的另一半（§4.19.2）：PORTSC 有七个状态变化位——CSC / PEC / WRC / OCC / PRC / PLC / CEC（p291），每口的变化位 OR 在一起、经 HCHalted 门控，形成内部信号 PSCEG；PSCEG 的 0→1 跳变才产生 Port Status Change Event——不是「某位=1 就发事件」（p293），且一口的事件在它的全部变化位清零之前被阻塞（PSCEG 回 0 才再开闸，p293 Note）。软件读 PORTSC 与事件环之间没有一致性保证：读到变化位置位，不代表对应事件已写进事件环（p292 Note）。置位/清零纪律：变化位由硬件或软件条件置位，系统软件写 '1' 清除（写 '0' 无效果），Chip Hardware Reset 或 HCRST 亦可清（p291）。

USB3 的 Disabled=软件写 PED='1' 可从（除 Powered-off 外）任一态进入——与 USB2 的 Disabled 完全两义。

§4.19.1 状态机概览（状态图）

读图注记（判据逐条对页）：

  • 简版口径：只画主线迁移与大泡；USB2 的 Test Mode 态、USB3 的 Compliance / Error / Loopback / Polling 态、两族的 Enabled 子态机（Figure 4-26 p275 · Figure 4-30 p285）、Polling 的 Training/CfgExcg/DbC 子态（Figure 4-28 p280 · Figure 4-29 p282）与 U1'/U2'/U3' 子态机（Figure 4-31/4-32/4-33 p286/287/289）不在本图——全图进出条件逐态归 §4.19.1 原文（p272–291）。
  • 大泡：虚线代表「任一态」——"Transitions associated with the large bubble may occur from any state defined within the bubble as long as the Conditions match."（p272）；USB2/USB3 到 Powered-off 的条件同为 Wr(PP='0') 或过流 OCA='1'（p274/p279），重上电回 Disconnected（p274/p279）。
  • Disabled 同名两义（不混写）：USB2 Disabled = 连接检出后的待复位态（PLS=Polling · 1,1,0,0，Figure 4-25 p273）；USB3 Disabled = 软件写 PED='1' 的链路禁用态（PLS=Disabled · 1,0,0,0，Figure 4-27 p278）。USB3 出 Disabled 走 Wr(PLS=RxDetect+LWS) 或 HCRST 回 Disconnected（p279）；USB2 Disabled 出口只有端口复位（p274）。
  • Enabled 到达两族不同路（不画成同一自动路径）：USB2 仅经端口复位——"When the Reset operation completes (PR = ‘0’), the port shall automatically advance to the Enabled state, setting PED and PRC to ‘1’."（p274）；USB3 attach 后链路训练+配置成功自动迁入 Enabled·U0 且置 CSC='1'（p279 · p281 · p295）。
  • 挂起域：U0/U3 是 Enabled 的子态——进入 U3 两族同写 Wr(PLS=U3+LWS='1')；恢复路径不同：USB2 主机先写 PLS=Resume（Resume 态时长由软件计时）再写 PLS=U0 经 RExit 回 U0（p277–278），USB3 主机直接写 PLS=U0 经 U3Exit 的 LFPS 握手回 U0（p289）；设备唤醒两族都置 PLC='1'（p277/p289）。
  • 记法：Wr(f=v)=软件写 PORTSC；不带 Wr 的 f=v=字段自动迁移；进入态时信号态（PP,CCS,PED,PR）被强制成该态定义值（p272 Note）。

xHCI 1.2b §4.10 Host Controller TRB Handling · p170–188 · §4.10.1 传输 TRB / §4.10.2 错误 / §4.10.3 事件 / §4.10.4 IOC 标志（页码已机核，见 EVIDENCE.md）

规范要义

传输执行是 xHC 的日常主业务：全配置 xHC 最多 255 台设备 × 每台 31 个端点 × 30 个端点可开 64K Streams——最坏约 5 亿条传输环，xHC 必须高效上报几百上千条环的完成状态，载体就是事件环上的 Transfer Event TRB。xHC 在一条 Transfer TRB 关联的传输完成时，评估完成状态与 TRB 标志，决定要不要为它生成事件：IOC=1 就生成事件，且事件一生成必伴随对宿主的中断；事件的 Completion Code 与 Length 字段如实回传源 TRB 的完成状态。下面这台「TRB 处理台」把这条主线开成一镜：取卡验 Cycle → 沿数据导轨搬票据 → 按结局冲出事件回执卡。（本页「xHCI 驱动」即规范原文所称 system software（系统软件）。）

三种结局、三种事件策略：正常完成只有 IOC=1 的 TRB 出事件（惯例是 TD 末 TRB 一枚，即 TD 完成事件——它同时宣告 TD 占用的环空间可回收）；短包（实际收到的字节少于 TRB 期望）只有在 ISP 或 IOC 置位的 TRB 上才出事件，Completion Code=Short Packet、Length=未写入数据缓冲的残余字节数，且 xHC 自动推进到下一 TD；错误无视 IOC/ISP 一律出事件，需停机的错误把端点打到 Halted、xHC 停在出错 TRB 上，恢复两步（Reset Endpoint 命令 + 软件清设备侧 halt）都成功后才准写门铃重启环。等时端点是例外族：没有握手，从不停机——错误、未服务（Missed Service Error）、环空转（Ring Overrun/Underrun）都只出事件，随后继续下一 ESIT。

§4.10.4 的通用规则一句话：IOC 置位就生成事件；想知道 TD 何时完成，就在 TD 末 TRB 置 IOC。短包事件可用 BEI 压掉中断；软件也可借 IOC 做及时的 Dequeue Pointer 更新，缩短错误恢复时间。标志组合逐条语义与错误分类见下方两张表格卡。

原文对照

“If upon transfer completion of a TRB the Interrupt On Completion (IOC) flag is set, the xHC shall generate a Transfer Event TRB.”

(xHCI 1.2b §4.10.1 p170)

IOC=1 是「必出事件」的最强信号——事件还必伴随对宿主的中断（同页 Note）。

“A Short Packet will trigger the generation of a Transfer Event TRB on the Event Ring if the Interrupt-on-Short (ISP) or Interrupt On Completion (IOC) flags are set in the TRB that the Short Packet was detected on.”

(xHCI 1.2b §4.10.1 p171)

短包不必然出事件——ISP/IOC 置位的 TRB 上才出；Length=残余字节数。

“The detection of an error during a USB transfer shall always generate a Transfer Event, irrespective of whether the Interrupt-on-Short Packet (ISP) or Interrupt On Completion (IOC) flags are set in the Transfer TRB.”

(xHCI 1.2b §4.10.2 p175)

错误是唯一无视标志组合的事件源——Completion Code 指明错误条件。

“All Transfer Ring error conditions force the state of the associated endpoint to Halted and require system software intervention to recover.”

(xHCI 1.2b §4.10.2 p176)

传输环错误一律停机等软件——例外是等时端点（同页：无握手、不停机）。

“The general rule for how the xHC should handle the IOC flag is simple: if the IOC flag is set, then generate an event.”

(xHCI 1.2b §4.10.4 p187)

IOC 语义的总纲：置位即出事件——例外（事件环满、PAE=0）见下方组合表。

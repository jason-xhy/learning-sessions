## 0. 依据与口径

### 0.1 两类值分界（防发明数值）

- **规范语义值**：字段值、状态名、流程、页码——全部指回 S1 章节（内含 pNN），本文引用形如「S1 §3.2（p73）」。任何 S1 没有的规范性数值一律不出现。
- **设计参数**：几何尺寸、世界坐标、时长、颜色、卡槽数等 S2 自由裁定项，标注〔设计参数〕或〔承 V2〕。未标注的数字默认按规范语义值对待。

### 0.2 术语口径（DESIGN §3.1 首用注，本文先行落实）

xHCI 驱动（规范称 system software）· Device Slot=设备槽 · TRB=传输请求块 · doorbell=门铃 · port reset=端口复位 · Default/Addressed/Configured 保留英文、首用注中文（默认态/已编址/已配置）· Enabled 首用注「已使能」· Command Completion Event=命令完成事件 · Transfer Event=传输事件 · PSCEG=端口状态变化事件生成信号（xHC 内部变量）· DCI=设备上下文索引 · PCS=生产者循环态 · DCS=出队循环态 · ERDP=事件环出队指针。

### 0.3 隐喻词口径

正文场景词汇只用 DESIGN §3.2 名单 + 追认十词（端子/檐/卡笼/计数轮/收件口/拉线/滑车/门架/卡库/拉杆）+ V2 追认六词（状态窗/读数屏/收件屏/传送带/格架/事件匣）。原超名单词已由主会话于 2026-11-10 在 DESIGN §8 裁定追认（登记见附录 B）；后续新增隐喻词仍照「先列表报主会话」流程。

## §B 三环流水线〔意见⑥〕

### B.1 公共构造（每环同构）

- **轨道**：钢架圆管（半径 0.14 wu）+12 只卡槽（亮钢 #5d6875，卡槽间距=弧长 2πR/12≈2.41 wu）〔承 V2 材质教训：近黑不可辨，一律亮钢〕。
- **TRB 卡**：1.24×0.56×0.06 wu，billboard 化立法（每帧 lookAt 相机，仅 +z 面贴字，断言 fwd·toCam≈1.00——〔承 V2〕P1-2 修法）〔意见③〕。
- **Link 回绕**：每环 slot 0=Link 槽（琥珀槽底）；slot 11→slot 0 走外侧回绕弧（半径 R+0.9 上拱）；卡过弧时卡角 cycle 片翻色（PCS=1 绿 #86bd7a ↔ 0 琥珀 #d9a860）；小牌「Link TRB · 环回绕，生产者循环态翻转」（S1 §4.3 环初值 PCS=1；回绕翻转演示为〔承 V2〕场景约定）。
- **读指针小旗**（已追认，附录 B）：每环一支 dequeue 旗标，沿卡槽步进指示消费位置（S1 §4 建模提示②「ERDP 读指针小旗」——事件环旗=ERDP 推进，写点=S1 §4.4 条 6）。

### B.2 命令环（下层 y=10.0，accent 琥珀）

- **铭牌**（HTML 白底浮签）：「命令环 · 唯一」——全规范仅一条命令环（S1 §4.1，p68 原句+xhci.h:1544），禁止出现第二条。
- **流转语义**：命令单（蓝边卡）从文书台打印机 → 飞至 slot 7 入环 → 消费点小旗步进；xHC 按入环顺序执行（S1 §4.1，p60）。**命令完成事件不走命令环**——一律入事件环回文书台（DESIGN §2 避雷，S1 §4.4 条 4）。
- **门铃联动**：命令单落位后 0 号大旋钮按压（DB Target=0，牌「0 号 · DB Target=0 · 命令」；与 EP0 门铃并存且分开刻——DESIGN §2 避雷；S1 §4.2，p83+xhci-ring.c:429–441）。
- **卡型**：Enable Slot / Address Device（卡面含 BSR 位与 Slot ID 同在第四字 word3——S1 §7.2 条 12）/ Evaluate Context / Configure Endpoint。
- **连接建筑元素**：命令单打印机、门铃 0 号旋钮、BSR 旋钮（Address Device 卡面 BSR 位联动）、Link 回绕弧。

### B.3 事件环（上层 y=13.6，accent 蓝）

- **铭牌**：「事件环 · 回执」。
- **流转语义**：xHC 产事件卡入 slot 1（东北，xHC 内部）→ 逆时针步进 5 格 → slot 6 西端脱离 → **空中走廊**（§I 坐标段）→ 文书台事件匣顶降落 → 停留（§J hold）→ 淡出〔承 V2 链路，参数化升级见 §J〕〔意见②③〕。
- **中断闪线**（铭牌「中断（可选）」）：事件环 slot 6 → 文书台状态窗 的细闪线（闪 3 次/事件）；**双形态立法**——闪线旁挂轮询探针小滑车（沿同线滑行读取），F0 卡+铭牌双处声明「中断可选，可轮询事件环运行」（S1 §4.5，p69 脚注 7——DESIGN §2 避雷：不得画成中断唯一）〔意见⑥〕。
- **ERDP 小旗**：事件卡被「驱动读取」时（事件匣开匣动画）小旗沿环步进一格（S1 §4.4 条 6，xhci-ring.c:3046–3073）。
- **卡型**：Port Status Change Event / Command Completion Event / Transfer Event（卡面带 Completion Code 字样时仅用 S1 已核值：Success——S1 §3.2 收尾，p74；Parameter Error——S1 §7.2 条 10，p100）。
- **连接建筑元素**：事件匣、中断闪线+轮询滑车、ERDP 小旗、Link 回绕弧。

### B.4 EP0 传输环（中层 y=11.8，accent 绿）

- **铭牌**：「EP0 传输环 · 1 号槽」——每设备槽各一条，演示只画当前槽（S1 §4 建模提示②；环分配 xhci-mem.c:1010）。
- **流转语义**：软件把三段 TD 写入环（DMA 可见写）→ 三卡依次落位 slot 5/6/7（西段，面向文书台，cycle 从 PCS=1 起，S1 §4.3）→ 1 号旋钮按压（DB Target=1，牌「1 号 · DB Target=1 · EP0（DCI=1）」；DCI=(端点号×2)+1——S1 §4.2，p82；宏证据 xhci.h:313–314）→ xHC 执行 → 请求票据沿缆东行（§C）→ 回包西行入 8 字节托盘 → Status 段 Transfer Event（IOC=1）入事件环。
- **FS 支线闸口**（已追认，附录 B）：EP0 环西段旁立门架拱口+牌「FS 才需先读 8 字节（p72）；LS/HS/SS：8/64/512 直接绕行」（S1 §3.1）〔意见⑥〕。
- **指针光束**：DCBAA 1 号格 → EP0 环 slot 5 的细光束（TR Dequeue Pointer=环首段地址|DCS——S1 §5.1 表，xhci-mem.c:1197–1198）。
- **连接建筑元素**：门铃 1 号旋钮、8 字节托盘（DMA 光束端点）、FS 支线闸口、DCBAA 格架（指针光束）、USB 缆（票据接力）、Link 回绕弧。

### B.5 DMA 光束〔意见⑥〕

- 文书台（表格卡/托盘）↔ 环卡槽之间的蓝色直写光束：色 #5f86e8、半径 0.07 wu、单程 1.5s@1×、脉冲球往返〔承 V2 修复值：0x7c9ff0 过曝白线教训〕；铭牌「DMA 直写」（S1 §4.6：上下文与环皆 DMA 内存，写不经人手）。三处用点：命令单写入命令环（F4）、三 TRB 写环（F7）、8 字节回包落托盘（F7）。

### B.6 连接矩阵（每环 ↔ 建筑元素总表）

| 环 | 入/写位 | 出/消费位 | 关联建筑元素 |
|---|---|---|---|
| 命令环 | slot 7（西南，文书台方向） | 消费点小旗 | 打印机、门铃 0 号、BSR 旋钮、卡库（Enable Slot 抽卡联动） |
| 事件环 | slot 1（东北，xHC 内部） | slot 6 → 走廊 → 事件匣 | 事件匣、中断闪线/轮询滑车、ERDP 小旗 |
| EP0 传输环 | slot 5/6/7（西段，DMA 写入） | slot 1（东北，xHC 执行） | 门铃 1 号、托盘、FS 闸口、格架指针光束、缆 |

### B.7 双口径立法（S1 §7.2 条 4/5 红线落地）〔意见⑥〕

- **主线（默认预设「全速」）= 规范建议路径**：F6 Address Device（BSR=0，槽 Enabled→Addressed，p77）→ F7 GET_DESCRIPTOR 前 8 字节（p72–73）→ F8 Evaluate Context（A1=1）更新 EP0 MPS（p74）。F6/F8 卡面带角标「规范建议路径」。
- **新增预设「Linux 实路径」= 完整两步流序列**（S1 §6.3：hub.c:5056–5061 先 enable 再读 8 字节；hub.c:4785–4790 编址走 address_device）：F4 Enable Slot（不变）→ F6 变体=BSR=1（使能 EP0，槽 Enabled→Default，无 SET_ADDRESS 票据，p77）→ F7=读 8 字节（Default 态通信）→ F8 变体=BSR=0 补编址（xHC 代发 SET_ADDRESS，槽 Default→Addressed，p97）。此预设 F8 注记卡：「驱动不重写 EP0 MPS（初值按速度一次写入；FS 初猜 64——xhci-mem.c:1125–1128）；Evaluate Context 不在枚举链（S1 §6.3）」。
- **不混写红线**：同一预设内场景动画只演本路径；差异只出现在注记卡文字层。全速主线 F7/F8 挂「Linux 实路径」对照注记卡（三点差异：BSR=1 先通信／BSR=0 后编址／不重写 MPS）；Linux 预设对称挂「规范建议路径」回看卡。两卡永不合成一张。
- **BSR=1 legacy 教学预设保留**（承 V2）：只演单分支结局（槽 Default、禁止 SET_ADDRESS——p76–77），不冒充 Linux 完整路径；与「Linux 实路径」预设并存、语义分立。

## 1. 本环节定位

S2 把 S1 解读文档（规范/代码事实唯一引用源）翻译成「xHC 启机车间」3D 课件的完整场景与模型方案：布局、三环、缆与信号、12 工段分镜、配色板、纹理清单、互动递进、遮挡预案、动画时序。主件 `S2-scene-design-设计.md` 是 S3（DSL）的直接输入、S4（Three.js 施工）的设计基准、S6（Blender 材质工厂）的任务书来源。

**需求主轴 = 用户 8 条验收意见**（notes/43-heeli-3d-design-2026-11-09.md「V1 上线+用户验收反馈」节，V3 逐条响应）：
①交互速度慢 → 速度分层设计；②事件流转太快 → 放慢+终点停留；③流转被遮挡 → 可见走廊+起终点标；④质感粗糙 → 纹理质感方案（对接 S6）；⑤状态变化不生动 → 真实设备插入动作；⑥场景贴 xHCI 语义（三环=环形流水线、DMA、中断、USB 实体缆+方波信号）；⑦知识面板太长 → tab 化；⑧互动：组装 URB/TD/TRB、操作 doorbell、获取事件。

## 4. 验收要点

1. **8 条意见逐条有可实施方案**：每条意见在主件中有明确落点章节与可执行设计（能直接翻译成 S3 DSL 参数或 S4/S6 工单），并给出继承 V2 什么、升级什么。
2. **布局可建**：坐标系约定+关键尺寸表+各元素世界坐标范围齐备，S3 零猜测可写 DSL；F0 全景完整性约束含视口 ~1024px 口径、必入画元素清单、机位基线与右缘裁剪图人验协议（V2 自检协议继承）。
3. **三环语义贴规范且双口径分立**：命令环唯一/事件环回执/EP0 传输环按 S1 §4 建模提示造型；门铃 0/1 分刻；DMA 光束；中断可选（闪线+轮询双形态）；主线演示=规范建议路径，「Linux 实路径」（BSR=1→读 8B→BSR=0）只走对照注记卡与独立预设，不混写（S1 §7.2 条 4/5）。
4. **配色板具体到色值**：deep-dark 基调全量色板（背景/三区/三环/卡片族/状态灯语义色/告警/文字）每色给 hex+用途；承载文字配对全部给实测对比度比且 ≥4.5:1；三方色相遵守 DESIGN §3.3。
5. **纹理清单 S6 可直接开工**：逐材质给贴图类型/尺寸/做旧特征/程序化生成指引；给出 base64 内嵌预算（≤+1.5MB）下的优先级砍序。
6. **12 工段分镜可执行**：每工段有机位值域、场景状态变化清单、事件流转路径（含起终点小标文案）、面板内容要点、至少一个「物理动作感」瞬间。
7. **互动三关可施工**：每关给入口/操作/反馈/完成徽章/失败提示，判据文案全部带 S1 锚点（pNN）；主线工段与动手台解耦声明在案。
8. **时序全参数化**：全局速度系数贯通规则+每动画参数的基准值/缩放规则/取值范围成表，S3 照表写 timeline；停留时长参数化且默认档真正放慢（修正 V2 hold 公式在 0.5× 档退化为常数的问题）。
9. **遮挡预案可验证**：逐机位必在画元素清单；标签-几何邻居表（每个标签登记几何邻居，供探针扩检）；走廊坐标段（几何断言可查）；billboard 化立法；细节层字号台阶登记。
10. **红线全过**：数值零发明（规范语义值全部指回 S1 章节；几何/时序/颜色为设计参数须显式声明分界）；DESIGN §2 避雷零复现；语言门退役词扫描（豁免={回执}）；术语 §3.1 首用中文注；隐喻词超名单者列入「待登记」表报主会话；只写 pipeline/ 四文件。

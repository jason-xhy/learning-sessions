## 4. 验收要点

1. **可追溯性（核心）**：每条规范事实带印刷页码（pNN），每条驱动事实带 `file:line`；行号与页码必须是本轮现场核实，不是凭记忆或沿用旧文档。
2. **数值零发明**：文档中出现的每个字段值、状态码、宏值都能指回 pNN 或 file:line；规范未给的数值（如 USB2 复位期间 PLS）显式标注「不造数」。
3. **EVIDENCE 基线逐条收录**：V1 §2 内容断言逐条出现在解读文档中并标注「已核（EVIDENCE …）」；与 V2 §7 相关的数值行同口径收录。
4. **避雷零复现**：DESIGN §2 每条避雷项在易错点清单中有对应条目与文档内锚点。
5. **语言门**：退役词族自查（scripts/scan_words.py RETIRED_WORDS 全表对本三文档扫描），豁免集仅限回执（DESIGN §3.2 机器隐喻词追认 + EVIDENCE 门 4 先例）；术语沿 DESIGN §3.1 首用中文注。
6. **只写 pipeline/**：不动 src/、index.html 及其他任何目录（PIPELINE §5，S1–S3 零 src/ 接触）。
7. **S2 可消费性**：S2 设计师只读本文档即可拿到全部 3D 场景所需事实与隐喻锚点，无需回读规范 PDF 或源码。

# S3-设计 —— DSL schema 结构设计（V3 流水线环节 3）

制定：2026-11-10 ｜ 执行：S3 worker ｜ 需求：S3-需求.md

## 1. 总原则

- **数据-逻辑分离**：JSON 只写声明式数据（几何/参数/文本/断言阈值）＋显式推导公式；动画编排用「动作原语＋参数引用」表达，解释器在 S4。
- **单源双消费**：以消费者切面分区——S6 只读 `materials`(pbr)+`textureRequests`；S4 读其余全部分区；`meta` 承载跨消费者口径（坐标系/单位/速度模型/derived）。
- **溯源三级**：分区级 `s2` 字段标 § 号 → 字段级溯源表在 S3-dsl-说明.md → S2 未给值进 `meta.derived`（value+formula+basis），正文引用写 `"derived":"dXX"`。

## 2. 顶层分区与划分理由

| 分区 | 内容 | 主消费者 | S2 源 |
|---|---|---|---|
| meta | 版本/单位/坐标/bbox/render/速度模型/camAdapt/ui/derived | 双方 | §A.1/§A.5/§J.1/§I.1 |
| materials | pbr 材质（S6）＋flat 平色与灯语义（S4） | S6＋S4 | §E.1–E.7 |
| sceneGraph | 逐实体几何/材质引用/牌文＋labels 19 锚点 | S4 | §A.2–A.3/§I.3 |
| rings | 三环公共构造＋每环语义＋连接矩阵 | S4 | §A.4/§B |
| cable | 缆曲线/插头/方波信号段/方向语义 | S4 | §C |
| corridor | 走廊曲线＋分段断言 | S4 | §I.4/§I.1 条5 |
| cameras | 16 机位＋camAdapt＋F0 检查单 | S4 | §A.1/§A.5/§D/§G/§I.2 |
| timeline | params 36 行＋F0–F11 状态机＋F12＋预设覆盖 | S4 | §D/§J/§B.7 |
| interactions | 解耦＋L1/L2/L3＋quiz | S4 | §G/§K |
| panel | 活指标＋4 tab＋窄屏 | S4 | §H |
| textureRequests | 12 材质任务书 | S6 | §F |

划分理由：S6 切面=材质与纹理两分区自足；S4 切面=空间（sceneGraph/rings/cable/corridor）＋视点（cameras）＋时间（timeline）＋交互（interactions/panel）。§A 拆进 meta（坐标系）＋sceneGraph（实体）＋cameras（机位）；§B/§C/§D/§G/§H/§I/§J 各有唯一分区对应。

## 3. 命名约定

- 实体 id：camelCase，域前缀 sw/hc/dev/env/rings/fx；环内槽位记法 `ringEvt.slot6`。
- 参数 id：§J.2 行语义缩写大写（FLY/HOLD/…），36 个，与 §J.2 行序一致便于核对。
- 标签 id：§I.3 原名不改（zone-sw…plate）。
- 材质 id：`m` 前缀（mCabinetSteel…）；平色 id=用途名（pageBg…）。
- derived id：`d01` 起两位序号。

## 4. 单位与坐标

wu／s／deg／sRGB #rrggbb；右手系 Y 上、+X 东、+Z 南（§A.1）。bbox 用开区间语义（边界相切不算重叠，承 S2 修复轮自检口径）。S2 给区间的件写 `bbox{xyz区间}`，给中心/半径的件写 `pos+size/radius`——两种形态都不做额外换算。

## 5. 引用完整性规则（可机检）

五类引用边：`entity.material → materials.id`；`timeline.stages[].camera → cameras.list[].id`；`action.param → timeline.params[].id`；`labels[].host → entity.id`；`rings.rings[].label → labels.id`。实体/标签/参数/机位/材质 id 全局唯一。校验脚本 `s3_dsl_check.py` 全量跑，零 FAIL 才过。

## 6. timeline 表达法

- `params[]`：36 行，`{id,name,base,at05,at2,rule,note,use[]}`；rule ∈ `/k`｜`×k`｜`max(1.2, HOLD_SET/k)`；UI 固定 0.25s、动手台等待封顶 6s 在 `meta.speedModel`（§J.1）。
- `stages[]`：`{id,step,title,page,camera,moves[],state[],flow[],panel,physical,occlusion?,variants?}`
  - `moves[]`：动作原语（devSlideIn/plugPush/bellPress/…）＋param 引用——参数值不在动作里重复写。
  - `state[]`：读数/灯/槽态变化，逐条带 s1 锚（规范语义值可溯源）。
  - `flow[]`：流转卡，起/终小标**逐字**（S4 直接渲染），route 字段给路径模板串。
- 工段总时长不写死（derived d31：Σ动作+HOLD，S4 播放器排程）。
- `branches`：预设 chips×5 → 每预设的工段覆盖差异；不混写红线（§B.7）＝差异只出现在注记卡文字层、对照卡永不合成。

## 7. 断言与探针数据（判⑥）

- `corridor.assertions`：分段口径（起步段弧长 <1.0 wu 豁免距离断言、y 单调上升、不进环带 bbox；巡航段距轨道管 ≥1.2 wu；全程 y ≥4.0；x ≤−7.5 方允许降高）。
- `labels[].neighbors`：探针扩检输入（标签 bbox vs 几何邻居 bbox 两两求交 overlap>0.15=0 对）。
- `rings.common.cardBillboard.assert` = fwd·toCam ≈ 1.00（每帧 lookAt、仅 +z 面贴字）。
- `cameras.f0Check`：1024px 口径＋必入画清单＋右缘余量 ≥1.0 wu＋裁右缘 1/3 人验＋390px 窄屏加拍。
- `meta.ui.detailLayer`：细节层登记清单（F4 命令环卡/EP0 环卡面字段/格架格号/缆插头丝印）——EVIDENCE 义务的机器可读形态。

## 8. derived 机制（S2 未给值的唯一合法入口）

`meta.derived[]`：`{id,value,formula,basis}`。归拢范围五类：
1. **几何缺省**：S2 只给区间/锚点的件（门铃旋钮布局、格架格心、灯位、桌面件 y/z〔引 S2-输出 §7.1 自检口径〕、板厚等）；
2. **微动作缺项**：S2-评分⑤指出的 3 项（MPS 翻新高亮/事件匣开匣/Link 弧 cycle 翻色）——统一 0.5s=J.2 打勾 0.4 与复位按钮 0.6 的算术中值；
3. **修复轮联动失配消解**：走廊末点 (−11.5,4.1,0.8) 与修复轮事件匣 x[−11.2,−9.8] 的落点公式（d15）；
4. **行为默认**：F0 不设通过门／quiz 自由进入（S2-评分⑧ remark 的显式化）；
5. **材质归属缺省**：桌面五件/格架等按 §E.7 材质族就近归属表。

## 9. 自检方案

1. `python3 -I -m json.tool` 解析。
2. `s3_dsl_check.py`（Write 落盘执行）：结构计数（12 工段/36 参数/19 标签/3 环/12 纹理请求）＋五类引用解析＋标签文本逐字对照（脚本内嵌期望表）＋数值抽查（~30 项直接对 S2 断言）。
3. 语言门：scan_words RETIRED_WORDS 扫 `S3-dsl-说明.md`/`S3-输出.md`，非零集应 ⊆{回执}。
4. 遗留登记进 S3-输出.md。

## 10. 风险与预案

- **走廊末点失配**：§I.4 末点 (−11.5,4.1,0.8) 与修复轮事件匣 x[−11.2,−9.8] 有 ~0.3 wu 西偏（S2 修复轮未联动 §I.4）——DSL 不改 S2 控制点，以 derived d15「落点=匣顶面中心」消解，S3-输出 上报主会话备案。
- **PBR null 项**：屏面玻璃/格架塑料 S2 未给 PBR 区间——materials 允许 null＋注记「S6 裁定」，不发明数值。
- **S2 未给内容槽位**：原文对照六条/quiz 题面——登记数量/页码范围/取材规则，内容定稿留 S5。

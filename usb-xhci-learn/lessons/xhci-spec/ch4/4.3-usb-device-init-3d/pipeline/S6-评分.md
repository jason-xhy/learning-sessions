## deskRowStd/knotStd 重标定建议（③=9.2≥8.5 → 走重标定路径；补光授权不建议）

**实测基准（scorer 独立，deskCloseup 同机位同灯光，v3m=纹理回灌 / v3k=占位档基线，1448×908 帧）**：

| 判据（64px 窗 / 桌面带） | v3m | v3k | 倍率 | 判别力 |
|---|---|---|---|---|
| row-mean-std（s6_desk_check 默认 crop） | 7.3 | 6.9 | 1.06× | **死判据**（行均值把横纹抹平） |
| row-mean-std（纯桌面带 0.03,0.615,0.67,0.135） | 5.34 | 5.32 | 1.00× | 死判据 |
| 节疤定点窗 std（868,548） | 4.6 | 0.9 | 5.1× | 强，但坐标敏感 |
| 节疤区 64px 最优窗 std（x780–1000,y470–620 搜索） | 4.63 | 2.34 | 1.98× | **强且鲁棒** |
| gradY-mean（桌面带垂直梯度均值=横向木纹能量） | 2.070 | 0.513 | 4.0× | **强** |
| 各向异性 gradY/gradX（木纹方向性） | 32.6 | 12.7 | 2.6× | 强 |
| 桌面均值亮度 | 12.6/255 | 14.3/255 | — | 亮度天花板实证（细节被压在 [0,45] 带，V2 的 40–59 系 V2 rig 数值） |

**建议 V3 截图级判据（语义=「木纹可见/节疤突出」，deskCloseup 帧固定 crop 下）**：
1. **木纹可见**：gradY-mean ≥ 1.2（=v3k 基线 2.3×，v3m 现值 2.07 余量 1.7×）**且** 各向异性 ≥ 20（v3k 12.7 拦在门外，v3m 32.6 过）——两条件联合锁「有横向纹理且确为横向」；
2. **节疤突出**：节疤区 64px 最优窗 std ≥ 4.0（v3k 2.34 拦、v3m 4.63 过，双向余量 ~2×）——用暗窗搜索模式免坐标标定；
3. **纹理级代理门维持主门**（check_textures.py：节疤 local-std ≥35+ΔL ≥18+全 map 健康，已全绿）——截图级为放大目验的机检佐证；
4. row-mean-std 降级为报告值不再作门（1.0× 判别力实锤）；worker 提议的「≥v3k×1.25」施于 row-mean-std 会误杀自家终版（7.3 < 6.9×1.25=8.6），不可采。
5. 落地：s6_desk_check.py 加 `--mode v3`（gradY/aniso/knot-window 三判据，参数化 crop/窗宽），既有 `--row-req/--knot-req` 形态保留兼容 V2 口径复现。

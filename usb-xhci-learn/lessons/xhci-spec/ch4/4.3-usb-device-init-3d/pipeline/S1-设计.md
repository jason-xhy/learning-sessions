## 2. 按什么顺序（执行序）

1. **判据通道先校准**（教训先行）：旧提取目录 `notes/.xhci-extract/` 页标与现行 PDF 偏移 +12，先重产现行提取文本并以三条 needle（CCS p71、§4.3.2 p75、BSR p76–77）对表，确认印刷页 = PDF 页后才开始摘录。
2. **规范通读**：按 §4.3 正文顺序 p71→p80 通读一遍，建立十二步骨架；随后读引用面（§4.5/§4.6.5/§4.19.2/§4.1/§3.3/脚注 7），只取 §4.3 行文直接引用到的条目。
3. **驱动取证**：按"§4.3 每一步在驱动里的落点"逐个 grep 函数名 → Read 函数体 → 记 file:line。顺序：设备插入/端口（xhci-hub.c）→ Enable Slot（xhci_alloc_dev）→ 数据结构分配（xhci_alloc_virt_device）→ 上下文填充（xhci_setup_addressable_virt_dev）→ Address Device（xhci_setup_device/queue_address_device）→ 门铃（DB_VALUE 宏 + ring_ep_doorbell/ring_cmd_db）→ 事件环（xhci_irq→handle_events→三事件分发）→ EP0 传输（queue_ctrl_tx→giveback_first_trb）→ usb core 调用侧（hub.c 三处）。
4. **组织成文**：按 S2–S7 消费视角重排（不按阅读顺序），每章 = 规范事实 + 驱动证据 + 建模提示。
5. **收尾核对**：EVIDENCE 逐条对照、避雷逐条收编、语言门扫描。

## 3. 如何摘录（防发明数值的三道闸）

1. **页码闸**：规范事实一律带 pNN；引文取提取文本原句，缩短时用 needle 短语（避开 PDF 断行——页码门教训在案），关键全句（如四信号句、PSCEG 句）保留完整句形。
2. **行号闸**：驱动事实一律带 `file:line`；行号来自本轮 grep -n / Read 输出，不引用记忆值。凡发现"任务提示函数名与现行内核不符"（已发生一处：xhci_setup_addressable_val_dev → 现名 xhci_setup_addressable_virt_dev），记入易错点清单新坑节。
3. **双源闸**：同一事实同时有规范页码与驱动行号的（如 DCBAA 软件装载、门铃分刻、槽状态迁移），双源并列展示；只有单源的显式标注（规范事实 / 驱动行为）。

规范未给数值的场合（USB2 复位进行中 PLS、MaxSlotsEn 具体值等）沿用 V1 口径：**显式写「规范未给，不造数」**。

## 4. 如何组织（消费视角章节法）

- 章节 = 任务书 ①–⑧ 的直接映射（见 S1-需求.md §3），每章内部固定三段式：**规范事实表（带页码）→ 驱动证据（带 file:line）→ 建模提示（S2 指引）**。
- 事实表列固定为：事实 / 规范判据（pNN） / 驱动判据（file:line，如有） / 角色（软件|xHC|设备，仅 ① 章） / EVIDENCE 基线标注（如有）。
- 建模提示的隐喻词白名单：DESIGN §3.2 机器隐喻词（工位/文书台/试验盒/托盘/轨道/回执/储物柜/命令单/表格卡/收件匣/铭牌/旋钮/闸刀/就绪灯/灯排/票据…）+ 追认 10 词 + V2 追认六词（状态窗/读数屏/收件屏/传送带/格架/事件匣）。超出名单的画法需求写入「待登记」而非自造词。
- 十二步主表用规范化步骤号（1–12），并显式注明规范 PDF 原编号断裂（§4.3.3 从 4. 起、§4.3.6 从 12. 起）——避雷条目，禁止照抄伪编号。

## 5. 自检方案（收尾时逐项过）

1. 覆盖面 ①–⑧ 逐项打勾并指回章节号。
2. 可追溯性抽全检：文档中每个 pNN 在本轮提取文本中出现过对应内容（写作时已逐一取自 awk/sed 输出，非记忆）；每个 file:line 来自本轮 Read/grep 输出。
3. EVIDENCE V1 §2 逐行对照表（附录）——每行指回本文档收录位置；V2 §7 数值行同口径。
4. 避雷清单逐条对照表——每条有文档锚点。
5. 语言门：用 scan_words.py 的 RETIRED_WORDS 全表对三份 S1 文档做计数扫描，期望非零集 = {回执}（豁免依据：DESIGN §3.2 + EVIDENCE 门 4 先例）；出现其他词即改写后复扫。
6. 零范围越界：git status 确认只新增 pipeline/ 四文件。

## 6. 风险与预案

- 规范表格跨页断裂（Table 4-1 槽状态表横跨 p85–86）→ 摘录时人工拼行并逐格核字段值。
- 驱动大函数（xhci_setup_device ~185 行）→ 只摘与 §4.3 对应的关键行，上下文 ±5 行内理解，不整函数粘贴。
- usb core 侧调用链（hub.c）非 xhci 文件 → 单独标注"usb core 侧"，避免与驱动行为混淆。

# S6-设计 —— Blender 材质工厂怎么做（V3 S6）

产出：2026-11-11 ｜ S6 worker ｜ 上游：S6-需求.md。三段：①生成管线与逐项节点方案 ②压缩打包与注入链 ③体积预算分配与自检方案。

## ① 生成管线（gen_textures.py，blender -b 无头）

**总体**：每纹理一张 1×1 平面（UV 0..1 全覆盖）+ 专属节点树材质；Cycles CPU samples=1；逐 map 改接 `Emission→Material Output` 后 `bpy.ops.object.bake(type='EMIT')`（数值链直出，不受光照影响）；normal 用 `bake(type='NORMAL', normal_space='TANGENT')`（Bump 链保持接在 Principled）。图片 datablock `float_buffer`，数据图保存前 `colorspace_settings.name='Non-Color'`（线性直写），albedo/emissive 用默认 sRGB 编码——与 three.js 侧（albedo SRGBColorSpace / 数据图 NoColorSpace）严格对偶。env 单独走全景相机渲染（Cycles PANORAMA EQUIRECTANGULAR）。

**可平铺性**（占位档 repeat 1.2–6 要求 tile 无缝）：Blender 噪声非周期，bake 后由 post_tile.py 做 wrap crossfade（边缘 8–12% 线性交叉渐变，法线图混合后重归一化）；强特征（节疤/指纹/锈斑/灯池/抛光斑）一律置于中心安全区（UV 0.14–0.86），不被渐变带触碰。

**尺寸口径**：textureRequests px=长边上限；纵横比按表面对象匹配（地板/桌面 2:1 类取 1024×512；方面板 1024²/512²；小件 256²/128²）。逐项在输出文档记录。

**roughnessMap 编码口径（全表统一）**：下表 rough 链中 [a,b] 调制系数一律换算为**绝对值输出**——`abs = mid + (f−1.0)×(r1−r0)/2 ×2`，即 f=1.0→区间中值、f=0.85→r0、f=1.15→r1（r0/r1=§E.7 roughness 区间）；注入时材质标量置 1.0，乘积仍落区间（见 ② engine.js 条）。

## ② 压缩打包与注入链

**链路**：`gen_textures.py`（Blender）→ `out/*.png` + manifest.json → `post_tile.py`（PIL 平铺化+sanity，回写 manifest）→ `check_textures.py`（验收机检，FAIL 即停）→ `pack_textures.mjs`（node：逐 map 择优编码 → `src/textures.gen.js` + 预算账）→ `build.mjs`（SRC 数组头部插入 textures.gen.js，位于 engine.js 之前）。

**编码策略**（逐 map 择优、以实测为准）：albedo/emissive → JPEG q86（拉丝/木纹线族测 PNG-256 色对比）；rough/ao → 灰度 PNG 或 WebP（平滑低频）；normal → 候选 {PNG, WebP lossless, JPEG q92 subsampling=0}——正常图 XY 双数据通道禁 4:2:0 色度抽样；择优=同视觉档下最小字节。data URL mime 随编码。

**X43_TEXDATA 形态**：`{gen, textures:{texNN:{repeat:[rx,ry], normalScale:n, maps:{map|roughnessMap|normalMap|aoMap|emissiveMap:{url,mime,w,h}}}}, env:{url,mime,w,h}}`。

**注入点（src 三件 + build）**：
- `engine.js`：新增 `applyTexData(m, req)`（TextureLoader 逐槽加载：albedo/emissive→SRGB，其余 NoColorSpace；repeat 同步至全部槽；normalScale 设置；加载回调 `m.needsUpdate`；无数据 return false）；`mat()` pbr 分支在占位纹理之后调用，命中则替换/增补 map/roughnessMap/normalMap/aoMap/emissiveMap（**roughnessMap=绝对 roughness 值域 [r0,r1]**，注入时标量置 1.0——8-bit PNG 存不下均值 1.0 的调制系数，绝对值域可线性编码；三.js 乘积 = scalar×map = 区间值，roughnessNote「贴图调制」语义不变）；导出 applyTexData 供 scene.js 复用。
- `scene.js`：地板 buildWorld——tex07 数据在场时跳过 texFactoryFloor 占位，材质改走 applyTexData（+aoMapIntensity 0.9）；数据缺席回落占位（现行为不变）。
- `main.js`：init 内 env 在场时 TextureLoader→EquirectangularReflectionMapping+SRGB→PMREMGenerator.fromEquirectangular→`scene.traverse` 中 metalness≥0.4 的 MeshStandardMaterial 挂 envMap（envMapIntensity：metal≥0.8 档 0.5，地板 0.15 档）—— plastics/rubber/cards 不挂，deep-dark 不整体提亮。
- 卡纸换绑（评估项）：桌面内衬卡 3 处 `mat("cardBg")`→`mat("mCardPaper")`（DSL 基色同 #1e2836，+纤维调制）；deskCloseup 目验有回归即回退（namePlate 背板已天然消费 tex08，换绑仅为增益项）。

## ④ 自检方案（收尾过门姿态）

1. **机检**：check_textures.py 全绿（tex03 三判据 + 全 map 尺寸对表 + 非恒值 + normal 主色 (128,128,255) 邻域占比）。
2. **构建**：`node build.mjs` ×2 sha 一致；体积增量实测 vs 预算表逐项。
3. **门**：S5 §7 十一门全复跑（console/lab/smoke/needle/retired/label_probe/shots v3m 31 件/perf 独占）。
4. **目验**：v3m-deskCloseup/deviceCloseup/F0/F4/F5/F7 对照 v3k 同机位——纹理细节可放大、无糊斑/平铺感、暗部层次改善、整体色调无回归；每帧留档 dev/iteration-frames/ 或 shots/。
5. **fallback 冒烟**：临时移走 textures.gen.js 重建 → 行为=占位档（构建过、页面可开）→ 恢复。
6. **输出文档**：12 项逐项表 + 门结果 + 体积账 + 偏差/遗留清单 + 工具通用化台账。

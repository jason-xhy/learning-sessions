# S7-设计 —— Remotion 包装实施方案（V3 S7）

产出：2026-11-11 ｜ S7 worker ｜ 依据：S7-需求.md、PIPELINE §1/§4/§6

## 1. 总体管线（三段式）

```
[录制] CDP screencast 逐工段帧序列  →  [组态] Remotion 合成（章节卡+画面+字幕+淡入淡出）  →  [渲染] renderMedia → media/S07-*.mp4
     pipeline/tools/s7_record.mjs        pipeline/tools/remotion-wrap/（项目）              node render_all.mjs
```

## 2. 录制设计（s7_record.mjs）

### 2.1 浏览器与通道

- **复用门工具同款 Chrome**：`headless=new --remote-debugging-port=0 --enable-unsafe-swiftshader --ignore-gpu-blocklist --allow-file-access-from-files`（与 drive.mjs 同形态，WebGL 行为与既有门一致）；二进制发现顺序同 drive.mjs（CHROME_PATH 可覆盖）。
- **CDP Page.startScreencast**（jpeg q90，1440×810）：**不用 playwright recordVideo**——recordVideo 从 context 创建即录，视频内含页面加载段、无确定性裁剪点；screencast 可在「页面就绪后、goto 前一刻」启动，视频起点与工段动画起点确定性对齐（误差=一次 eval 往返 ~10–50ms，≪1 帧）。
- 帧到达即 `Page.screencastFrameAck`；按到达时刻桶化到 24fps 槽（41.67ms/槽，同槽后帧覆盖前帧，空槽前帧前向填充）→ 每工段一目录 jpeg 帧序列 + manifest.json（帧数/实测时长）。

### 2.2 驱动序列（每工段）

1. 打开 `file://<lesson>/index.html`（一次启动复用一个页面），轮询 `window.__x43` 就绪（含 3.2s 装载余量）。
2. `__x43.setSpeed(1)`（k=1，视频节奏独立于页面默认 0.5×）。
3. `Page.startScreencast` → `__x43.goto(i)`：goto 内部自动处理积累态（i>applied 时 applyEnd 前序工段；i≤applied 时 rewindTo）——**与课件自动巡游同语义**，无需每段重载页面。
4. 轮询 `!__x43.playing()`（超时 150s 兜底）→ tail 2.5s（覆盖 done 后在途动画收尾）→ `stopScreencast`。
5. 逐段落盘 `frames/F<i>/`，manifest 记录 {stage, tend, frames, wallMs}。

### 2.3 参数化（PIPELINE §6）

`--stages all|0,1,… --fps 24 --width 1440 --height 810 --speed 1 --tail 2.5 --quality 90 --outdir frames --page … --dsl …`；工段数/机位全部运行时从 `__x43`/DSL 读取，不写死。

## 3. 分镜时长与字幕时间表（探针先行）

- `dev/s7_stage_probe.mjs`（一次性）：逐工段 `goto(i,{instant:true})` + `stageSteps(i)` 导出 `{i, id, title, tend(末步基准时刻), says:[{t, text}]}` → `dev/s7_stage_probe.json`。
- 用途：① 每段预期时长（tend/k=1 + 飞行托底，对表 stage_timing.mjs S5 实测）；② 字幕时间锚=say 步实测时刻（字幕与画面语义同相的机制保证）。
- 字幕表：`remotion-wrap/subtitles.json`（手工按 S2 §D 撰写文案，每段 2–3 行，from=say 时刻取整，to=下一行 from/段尾）。

## 4. Remotion 组态结构（remotion-wrap/）

```
src/
  index.js        registerRoot
  Root.js         14 个 <Composition>：S07-intro / S07-F00..F11 / S07-outro（1280×720@24fps）
  StageSeq.js     帧序列组件：按 useCurrentFrame 映射 frames/<stage>/NNNNNN.jpg（staticFile）
  Cards.js        章节卡/片头卡/片尾卡组件（黑底 #0b0f14 + 三区主色 #7c9ff0/#d9a860/#86bd7a 点缀）
  Subs.js         底部字幕带组件（rgba(11,15,20,.85) + #e8eef7， PingFang SC 系字体栈）
public/           = frames/（bundler publicDir 指向，帧序列不拷贝）
subtitles.json    字幕时间表（§3 产出）
```

- **片段时序**（每工段）：章节卡 2.0s（淡入 0.3s）→ 交叉淡化 0.4s 进画面 → 帧序列全长 → 段尾淡出 0.6s。章节卡/字幕/淡化为 Remotion DOM 层叠加，画面=帧序列，**零二次编码**（jpeg→H.264 一次）。
- **片头卡** 4s：课名+规范锚（xHCI 1.2b §4.3 · p71–80）+「12 工段演示」；**片尾卡** 6s：完工要点 + 自测引导（5 题 ≥4 通过）+ 动手台三关 + 「课件=index.html（同目录）」——不发明在线 URL（装机属主会话终验后）。
- 字体：系统栈 `PingFang SC, Hiragino Sans GB, Microsoft YaHei, sans-serif`（macOS headless Chrome 可用，零外链字体）。

## 5. 渲染与体积账

- `render_all.mjs`：bundle() → 逐 composition `renderMedia({crf})` → media/；先 crf=26 全量渲 → 体积账表 → 超 30MB 则升 crf（28→30）重渲最大段直至达标（目标 ≤28MB 留 7% 余量）。
- 命名：`media/S07-intro.mp4`、`media/S07-F00.mp4`…`media/S07-F11.mp4`、`media/S07-outro.mp4`。
- ffprobe 元数据自检：`npx remotion ffprobe`（Remotion 自带 ffmpeg/ffprobe，不装系统 ffmpeg——如确需系统 ffmpeg 先报主会话）。

## 6. HTML 演示视频入口

- `src/panel.js`：tab 行加「演示视频」（data-tab="video"），switchTab valid 表 +1；pane 内容=静态链接清单（14 段：段名+时长+大小，`<a href="media/S07-*.mp4" download>` 相对路径）+ 口径注（mp4=旁文件、全集体积、1× 节奏）。大小/时长为构建期事实，渲染完成后回填为字面值。
- 不动场景/时序/交互面；语言门预检新增文案（dev/retired_precheck.py 形态）。

## 7. 自检方案（对照 S7-需求 §4）

| # | 自检 | 工具/判据 |
|---|---|---|
| 1 | 逐段时长 | remotion ffprobe duration vs manifest 预期（±0.2s） |
| 2 | 花屏/黑帧 | 每段抽首/中/尾 3 帧 jpg 目验（Read 工具）；帧序列本身就是源，重点验合成后 mp4 抽帧 |
| 3 | 字幕/章节卡渲染 | 抽帧目验（CJK 缺字=豆腐块即 FAIL）；文案对表 S2 §D+S1 |
| 4 | HTML 全门 | sha×2 / 自包含 grep×4 / console_check / scan_words / needle 24 对 / label_probe / shots（复拍+抽 3 帧目验）/ perf_check |
| 5 | 体积账 | ls -la 逐段+合计 ≤30MB 表 |
| 6 | mp4 旁文件口径 | index.html grep `media/S07-` 仅 `<a href>` 形态；自包含 4 形态照旧 0 命中 |

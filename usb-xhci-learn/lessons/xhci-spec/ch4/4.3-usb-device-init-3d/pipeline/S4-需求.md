## 3. 验收要点（九门全绿 + DSL 忠实呈现 + 互动三关可用）

1. **构建可重复**：`node build.mjs` 两次 sha256 一致（无时间戳）。
2. **自包含零外链**：无 `<script src=`/`<link`/`@import`/`url(http` 资源加载；three.js vendored 内联。
3. **console 双域 clean**：drive.mjs 全工段（instant 巡检+动画工段）+ 互动全程（lab 三关/试错/预设切换）无 console 输出（Runtime.consoleAPICalled + Log.entryAdded 双监听）。
4. **语言门**：`scan_words.py retired` 残留 ⊆ 豁免（豁免=回执∪§3.2 全量含新增追认词）。
5. **页码 needle**：V3 引用面（S1/S2 页码锚）不回归——`xhci_spec_pagecheck.py` 全对 PASS。
6. **shots 全套**：机位升级 17 个（全景+16 预置）；另拍互动三关各 ≥1、试错路径、390px×2、quiz 槽位。
7. **标签不叠探针**：17 机位逐台 bbox 两两求交 overlap>0.15=0 对；+按 DSL labels.neighbors 做标签↔几何邻居扩检。
8. **LAB-CHECK 升级**：互动三关真实 DOM 点选链——L1 一步（对/错双路径）、L2 六步全链（错选拦截+即时纠错）、L3 自由组装（T1 判分/T2 BSR 双分支各自结局/T3 Linux 实路径排序挑战+错序拦截）+ L2→L3 徽章门；BSR 双分支不混写。
9. **zoomfs/交互冒烟**：键盘 ←→/空格、工段条点选、复位、全屏按钮、回到工位。
10. **性能门（新增，V1 用户反馈①）**：默认 0.5× 下全工段自动巡游一次 ≤8 分钟（墙钟实测）；巡游全程无 >100ms 长任务（PerformanceObserver longtask 探针）。

## 4. 纪律（PIPELINE §3 红线照抄）

- DSL=唯一事实源：**发现 DSL 疑似错误停下来报主会话，不许就地改数**。
- 内容红线：避雷清单零复现（命令环唯一/回执走事件环/软件 SET_ADDRESS 禁画法/中断可选双形态/四信号不造数/伪编号规范化）；数值唯一源=S1+DSL。
- 语言门 retired ⊆豁免；隐喻词已全量追认（走廊/流转卡/光束/闸口/扳机/小旗/灯池/翻牌/呼吸灯/信号段/打印机/钢卡座+V2 六词）。
- quiz 题面与原文对照六条=登记槽位（S5 义务）——本环节放占位文案并标注 SLOTS-FOR-S5。
- 纹理=null 区间（mGridPlastic/mScreenGlass PBR 区间）：程序化 canvas 缺省保底，材质系统留 S6 纹理注入口（textureRequests 有 data 用 data、无则程序化 fallback）。

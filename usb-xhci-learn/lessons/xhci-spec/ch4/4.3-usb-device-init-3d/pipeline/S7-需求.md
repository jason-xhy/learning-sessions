## 3. 硬规格

1. **分辨率/帧率**：1280×720（合成口径）；录制源 1440×810（与门工具 1440 布局同宽，等比 0.889 缩放入合成）；24 fps。
2. **体积账**：全集（14 段）合计 **≤30MB**（用户任务书目标）；渲染用 CRF 控制，超预算升 CRF 重渲。
3. **速度系数 1×**：视频观看节奏独立于页面默认 0.5×（录制前 `__x43.setSpeed(1)`）。
4. **字幕**：画面底部烧录（半透明深底+高对比白字）；文案全部出自 S2 §D 语义+S1 已核值——禁发明数值、禁规范伪编号；时间锚=编译步序 say 步时刻（实测，非估计）。
5. **录制语义**：逐工段积累态（goto(i) 自动 applyEnd 前序工段+播本段动画）——与课件自动巡游观看语义一致；每段覆盖相机飞行起点。
6. **语言门**：HTML 新增文案（tab 名/链接标注）过 retired 词表扫描，基线 total=24 不新增。
7. **自包含口径**：mp4 为旁文件不破坏单文件自包含（PIPELINE §4 已裁定）——HTML 内仅 `<a href="media/…">` 相对链接，零 `<script src>`/`<link>`/`@import`/`url(http`。

## 4. 验收要点（worker 自检 + scorer 独立复核面）

1. 每段 mp4 可播放、时长=预期（remotion ffprobe 元数据逐段核对）。
2. 无花屏/黑帧/半加载态（抽帧目验：每段至少首/中/尾 3 帧过目）。
3. 章节卡/字幕文字渲染正确（CJK 不缺字），字幕与画面语义同相（抽帧对表 S2 §D）。
4. HTML 侧全门复跑全绿：sha×2 / 自包含 4 形态 / console 双域 / 语言门 / needle 24 对 / label_probe / shots（含抽帧目验）/ perf 抽查。
5. 体积账逐段列表+合计 ≤30MB。
6. DSL 零改动；src/ 仅演示视频入口增量（不动场景/时序/交互）。

## 5. 边界与纪律

- 不 git commit（攒批态）；长命令后台+轮询；多行代码一律落盘执行。
- 录制/渲染中间产物放 `pipeline/tools/remotion-wrap/` 内（frames/ 为一次性大产物，渲染完成后可清理，输出文档记录）。
- 工具通用化（PIPELINE §6）：录制器参数化（工段表/机位/时长全部运行时探针获取，不写死），落 `pipeline/tools/`；一次性粘合（字幕表生成/合成注册）留 remotion-wrap/ 与 dev/ 并登记。

# S4-设计 —— DSL 驱动引擎怎么做（V3 S4）

产出：2026-11-10 ｜ S4 worker ｜ 上游：S4-需求.md。引擎形态=**DSL 加载适配层 + 手写构件函数库**（任务书推荐形态），保持 `build.mjs` 单文件装配链。

## 1. 总体架构

```
build.mjs ── 读 pipeline/scene.dsl.json ── 注入 const X43_DSL = {…}（首个 src 段）
src/engine.js   X43D：DSL 解析适配层（derived 引用/材质工厂/参数表/机位表/标签表/坐标换算）
src/scene.js    构件函数库（消费 X43D 几何表建模：地板/桌面行/机柜正面/门架/三环/缆/走廊/设备/FX）
src/stages.js   工段编译器（timeline.stages → [t,fn,arg] 步序）+ 预设/变体 + 面板内容编译 + 动作登记
src/lab.js      动手台三关状态机（interactions L1/L2/L3 + quiz 槽位）——独立状态机+setRender 钩子（承 V2 X43Lab 形态）
src/panel.js    面板 4 tab + 活指标 + chips×5 + HOLD 滑杆 + 徽章架（DOM 渲染，不持场景状态）
src/main.js     引擎装配（渲染器/自写轨道控件/标签投影/速度模型/巡游/试错/门 API window.__x43）
src/style.css   深色主题样式（承 V2 + 新增：标签左色条三档/徽章架/HOLD 滑杆/chips×5）
```

**数据流**：`X43_DSL` → `X43D` 解析（一次性）→ scene 构件建模（几何全取 DSL 值）→ stages 编译步序（参数全走 timeline.params）→ main tick 驱动（dt×k 速度模型）→ panel/lab 渲染。

## 2. X43D 解析层（engine.js）

| API | 职责 |
|---|---|
| `X43D.ref(v)` | 解析 `"derived:dXX"` / `"derived:dXX.key[.sub]"` 引用——递归查 `meta.derived[]`；**遇不可解析引用直接 throw**（禁自行发明缺省值） |
| `X43D.geom(e)` | 实体几何归一：bbox 区间 → {cx,cy,cz,sx,sy,sz}；pos+size/radius 直接用；两种形态不换算（承 S3-说明 bbox 开区间口径） |
| `X43D.mat(id, opts)` | 材质工厂：pbr → MeshStandardMaterial（basecolor 数组取区间中值、roughness 区间取中值；emissive 灯罩例外）；**flat → 直色**；`derived:d32.*` → 按归属表展开（`+边`/`+内衬` 复合色用双色构件实现）；null 区间（mGridPlastic/mScreenGlass）→ 程序化 canvas 占位纹理 + 保守 PBR 缺省（**S6 注入口**：材质 userData.texRequest=textureRequest id，S6 回灌时替换 map 即可） |
| `X43D.param(id)` | timeline 参数解析：`/k` → base/k（时长）；`×k` → base×k（速率）；HOLD → max(1.2, HOLD_SET/k)；k=meta.speedModel 当前档 |
| `X43D.cam(id)` | cameras.list 查表；`camAdapt` 按 meta（≤480px：全景类 k=max(1.5,68/d)+目标西移 7；近景类 ×1.16） |
| `X43D.label(id)` | labels 查表（anchor/barClass→d28 左色条/neighbors）；lbl-erdp=dynamic 随旗 |
| `X43D.slotPos(i, y)` | d01 公式 `[0.5+4.6·cos(30°i), y, −4.6·sin(30°i)]`（slot0 东/slot6 西/俯视逆时针） |

构建期机检（build.mjs）：结构计数断言（38 实体/17 机位/12 工段/36 参数/19 标签/3 环/12 纹理卡/34 derived）+全量 derived 引用可解析 + 引用边完整（材质/机位/参数/标签 host）。

## 4. 时间轴系统（stages.js）

- **编译**：`compileStage(dslStage)` 按 moves[] 序累积 base 时长（param→timeline.params[].base；无 param 的常驻态 lampBreath/ringIdleCruise/waveIdle/dmaBeamIdle 编译为 stage 附加态）→ `[t, fn, arg]` 步序；flow[] → 对应 evCard 调度（起/终小标逐字进流转卡画布 540×224、标题 36px/小标 28px）；state[] → 场景状态+活指标表（带 s1 锚入 panel）。工段总时长不写死（d31）。
- **速度模型**（meta.speedModel 贯通）：观看层 t=base/k（tick dt×k 实现承 V2）；方波速率 ×k 且按曲线实长（d29 运行时兜底）；UI 固定 0.25s；巡览层固定墙钟；HOLD=max(1.2, HOLD_SET/k)；动手台等待 /k 封顶 6s。
- **movers 库**（scene.js 动作集，两消费者共用：主线工段+动手台练习通道）：devSlideIn/plugPush(d24 弧顶 0.4)/portLight/triggerPull/lineFlash/buttonPress/signalQuad(四信号 0.35 间隔)/breathe(3 周期)/cmdFly/bellPress/drawerPick/gridHang/corridorFly+land+hold+fade 链/evCard(事件卡沿环步进 5 格→slot6 脱离→走廊)/tickCheck/cellFill/ringMount/trbPlace(0.6/卡)/gateLight/ticketEast/ticketWest/dmaFlash/trayPop/bsrTurn/domeColor(1.9)/plateFlip(180°+FLIP_HOLD)/mpsFlash(d14)/tdFast/inboxStack/dualFly(z+0.8/+1.2 分层)/epSlotsAllLit/ringFlow/lampSwitch/dcbaaWindowOn。
- **分支预设**（timeline.branches 全量接线）：fullspeed（默认·规范建议路径角标+F7/F8 对照卡）/hs（F7/F8 置灰）/usb3（F1 无 Disabled 帧变体+承 V2 契约跳 F2/F3/F7/F8）/bsr1（F6 旋钮 1 位无票据槽态灯→Default，只演单分支）/linux（F4 不变+F6=BSR1 变体+注记卡+F7 照演+F8=BSR0 补编址变体+注记卡）；contrastCards 三张+noMixRule（差异只在注记卡文字层，两卡永不合成）。
- **试错**：F5 入口「不填上下文直接编址」→ 空输入上下文抢发 Address Device → Parameter Error 红牌+输出上下文卡不动（p100）。

## 6. 互动状态机（lab.js，承 V2 X43Lab 形态）

- **解耦立法**照 DSL interactions.decouple：独立状态机+setRender 钩子/主线照常可用/判分不写回主线/练习触发同一 movers 库/入口=lab tab（第 3 位）/等待 /k 封顶 6s。
- **L1**：入口卡「按门铃」→ 相机 labL1+bell1 呼吸高亮引导；双入口（3D raycast 点旋钮 ∥ 面板按钮）；对=压下回弹+EP0 环一格步进+活文案+徽章「门铃上手 ✓」；错=DSL fail 文案逐字（knob0/emptySlot 两条）。
- **L2**：六步 s1–s6 逐 DSL steps（options/answer/fail 逐字；wIndex=0 固定展示；干扰项池 s4=DSL 已给 DB Target=0，s1/s2/s6 按 S1 同源值自拟干扰项=DSL 缺口补位并登记遗留）；模式=选项高亮+即时纠错+错选不推进；徽章「控制读三段齐 ✓」；徽章=L3 入门票（gate）。
- **L3**：无高亮无前置提示+提交统一判分；T1（上哪条环+按哪个门铃→判分+依据+Slot ID=1 回执演示）；T2（BSR 双分支各自结局演示、不混写）；T3（四卡排序 correctOrder=[0,1,2,3]+判分后对照卡）；三任务全对=徽章「值班工程师 ✓」。
- **quiz**：F11 讲解 tab，5 题 A/B/C（题面自 S1 拟=**SLOTS-FOR-S5 占位**，topics 6 项映射 §4.2/§6.1/§3.1/§1.1 步 10/§2.3/§6.3），≥4/5 通过可重做；d33 自由进入。

## 7. 面板（panel.js，4 tab 照 DSL panel 分区）

- 活指标四项（设备状态/槽状态/PLS/回执 n）+RuntimeStatus 活文案行常驻 tab 头上方。
- controls：速度 {0.5,1,2} 默认 0.5；HOLD_SET 滑杆 1.5–4.0 默认 2.0。
- tabs：讲解（工段标题+进度/正文卡组=DSL panel+state s1 锚/播放四键/chips×5/试错按钮 F5/自测题 F11）；字段与引文（fieldCards 三张=DSL 内嵌值逐字+quotesSix 六条〔S5 定稿槽位〕+流程原理+numericTable 九行=DSL 内嵌）；动手台；显示（剖视/标签/粒子+速度+滑杆+回到工位+窄屏说明）。
- ≤480px：面板初始折叠+半高贴底。

## 8. 纹理占位策略（S6 注入口）

- 材质工厂输出带 `userData.texRequest`（→textureRequests.items[].id）；本环节全部程序化 canvas 纹理保底：地板网格+灯池、桌面木纹（沿 X 波纹+节疤 2 处）、钢板拉丝+磨损、卡纸纤维、旋钮滚花、格架编号丝印 0..7、缆皮环向细纹、屏面抗反射微纹理；null 区间（格架塑料/屏面玻璃）按 S3-输出遗留 2 取程序化缺省（S6 会裁）。
- S6 回灌路径：`X43D.mat()` 替换 map/roughnessMap 即完成（无需改构件层）。

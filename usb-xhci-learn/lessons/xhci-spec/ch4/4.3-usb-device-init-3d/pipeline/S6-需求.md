## 3. 验收要点

1. **12 项逐项达标**：maps 类型/尺寸对 textureRequests（px=长边上限，纵横比按表面对象匹配并记录）；做旧特征逐条对应（污渍/划痕/磨损三件套显著且不糊）。
2. **tex03 机检（V2/V3 判据）**：木纹行亮度 std ≥40；节疤局部（64px 邻域）std ≥55；节疤心与周边 ΔL ≥18/255。
3. **体积账**：内嵌 base64 增量 ≤+1.5MB（含 env），目标 ≤1.45MB 留余量；超序=先砍小件 normal/ao（policy 砍序），砍项记录。
4. **近景经得起放大**：deskCloseup/deviceCloseup 重拍目验；无 mora 糊斑、无重复平铺感（平铺化修复后 tile 接缝不可见）。
5. **envMap 闭环 R2**：金属材质（metalness≥0.4）env 反射后 F0 三环辨识度改善，deep-dark 基调不破（整体不提亮、flat 色彩零回归——albedo 走「占位档同构调制层」策略，材质 color 通道不动）。
6. **门全绿**：sha×2 一致 / 自包含零外链 / console 双域 / 语言门 retired ⊆豁免基线 / needle 24 对 / label_probe / shots 31 件 / lab_check / smoke / perf（150s 量级持平，longtask 0）。
7. **DSL 零改动**；textureRequests 规格问题（如有）停下报主会话。
8. **占位保底**：无 textures.gen.js 时构建/运行行为=现行占位档（Blender 不进入构建依赖）；console 无新增输出。

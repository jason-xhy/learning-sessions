xHCI 1.2b §4.9 TRB Ring（4.9.1 传输描述符 · 4.9.2 传输环管理 · 4.9.3 命令环管理 · 4.9.4 事件环管理）· p149–170

规范要义

一条 TRB 环＝TRB 数据结构的循环队列，在生产者与消费者之间传递工作项——Work Item 由 1 个以上 TRB 组成，既可以是「待执行的操作」，也可以是「已执行的结果」（p149–150）。环分三种——传输环 / 事件环 / 命令环——各自的 TRB 类型集互不通用，但共用同一套底层机制与 TRB 模板（p150）。方向一句话：传输环与命令环由驱动生产、xHC 消费；事件环倒过来，xHC 生产、驱动消费（规范原文称 system software（系统软件））。三环机制的动态画面本节不重造——四机课各有一台机器负责演示，互链卡逐一标注「哪个环节由哪台机器演示」。

指针与位置标记：传输环、命令环的 Enqueue / Dequeue 指针都不是物理寄存器——xHC 与软件各自维护镜像副本（facsimile），入队位置由 Cycle bit 的翻转标记（p150 Note、p153）；事件环只有出队指针是物理寄存器 ERDP（Runtime 寄存器，p150 Note），入队指针 EREP 只是 xHC 内部变量（p164 Table 4-4）。初建或重初始化时全环 TRB 清 0，代表空队列（p151）；生产者按 PCS 值写 Cycle bit，消费者拿 CCS 比对——相等才可执行（p153、p157）。空＝Dequeue 等于 Enqueue；满＝Enqueue+1 等于 Dequeue，这个 +1 必须把 Link TRB 算进去（p151、p156）。

条目与分段：TD（传输描述符）＝1 个以上 TRB，除最后一颗外全部置 Chain bit；命令/事件 TRB 没有 Chain bit，命令描述符与事件描述符单 TRB 成项（p151、p152 Note）。显式造一个零长 USB 事务＝单 Transfer TRB 且 Transfer Length=0（p151）。环可以分段：Link TRB 把多段连成一环，环可跨页、可动态伸缩，但不得跨 64KB 边界（p151、p154–155）；事件环的分段走事件环段表（ERST），每段至少 16 个 TRB（p161–163）。命令环的独有约束：全规范只有一条命令环（§4.1 p68）、由 CRCR 管理（p150）、禁多 TRB TD（p160）。

原文对照

“A TRB (Transfer Request Block) Ring defines a queue, which is used to transfer Work Items between producer and consumer entities”
TRB 环就是一个队列——生产者与消费者之间传递工作项的通道。
xHCI 1.2b §4.9 p149
“There are 3 basic types or TRB Rings; Transfer, Event, and Command. Each type of ring defines an exclusive set of TRB data structures; however they all employ the underlying TRB Ring mechanism to organize their work items and the basic TRB template.”
环分三种：传输、事件、命令——TRB 类型集各自独占，底层机制与 TRB 模板共用。
xHCI 1.2b §4.9 p150
“If the Dequeue Pointer equals the Enqueue Pointer, then the TRB Ring is empty. If the "Enqueue Pointer + 1" = Dequeue Pointer, then the ring is full.”
空＝Dequeue 等于 Enqueue；满＝Enqueue+1 等于 Dequeue——+1 要把 Link TRB 算进去。
xHCI 1.2b §4.9 p151
“The Cycle bit field in a TRB identifies the location of the Enqueue Pointer in a Transfer Ring, eliminating the need to define a physical Enqueue Pointer register.”
Cycle bit 就是入队指针的位置标记——省掉一个物理 Enqueue 寄存器。
xHCI 1.2b §4.9.2 p153
“If the Producer encounters a Toggle Cycle flag set in a Link TRB it shall toggle the state of its PCS flag. If the Consumer encounters a Toggle Cycle flag set in a Link TRB it shall toggle the state of its CCS flag.”
遇 Toggle Cycle=1 的 Link TRB：生产者翻 PCS、消费者翻 CCS——回绕后双方的期望值各自翻转。
xHCI 1.2b §4.9.2 p154
“A fundamental difference between an Event Ring and a Transfer or Command Ring is that the xHC is the producer and system software is the consumer of Event TRBs.”
事件环与另两种环的根本差别：xHC 生产、系统软件消费。

# Fig4 概念与零件清单（动笔前定稿）

机器：**银行订单柜台**。软件在左侧下单窗口冲压订单托盘（命令 TRB），托盘滑入台面
8 槽命令环；台心旋臂吊（xHC 取件机构）把最老的一张吊到右侧办结台盖「办结」章，
回执卡从台身侧窗弹出、落入通往 Fig3 登记机的管道；软件凭回执把「设备上下文地址」牌
沿台面暗槽挂进台后 DCBAA 编号储物柜。CRCR 铭牌立在台右后：CRR 运行灯、RCS 翻色
旋钮、「运行中写入被忽略」小锁牌。Input Context 申请单夹立在下单窗旁，F3/F4 展开翻页。

一句话：**软件下单、xHC 办结；办结回执走事件环（Fig3），账本（设备上下文）挂进 DCBAA。**

帧序（合同 §2 Fig4，5 帧）：
- F0 全景：CRR 灯亮、RCS 指「生产轮色」，旋臂停驻办结台，指针牌都在 0 槽。
- F1 投单：Enable Slot（Type=9）托盘冲压→验卡→入 0 槽，enqueue→1，命令门铃
  （0 号门铃，DB Target=0）压下；门铃铭牌两行分刻 0/1 语义。
- F2 执行+回执：旋臂吊 0 槽托盘→办结台→回执（Type 33 · CC 1 Success · Slot ID 1）
  从侧窗出→入 Fig3 管道；软件把地址牌挂进 DCBAA 1 号格（§3.2.1/§6.1：写 DCBAA 的是软件）。
- F3 大单：申请单夹展开（输入控制上下文 A0 A1 / 槽上下文 / EP 上下文 0），
  Address Device（Type=11 · BSR=0）入 1 槽→办结→回执；柜顶「已编址」灯亮。
- F4 配置端点：夹子翻页（A2 A3 · EP1 OUT+EP1 IN 对），Configure Endpoint（Type=12 · DC=0）
  入 2 槽→办结→回执。读数 `命令 n · 完成 n · RCS 色`。

巡绕：一轮播完回 F0 时环回绕（过 7 号 Link TRB，TC=1），RCS 旋钮翻色、
托盘/回执色标换色，DCBAA 牌保留（账本不擦）。

零件清单（实体件 ~66，线刻另计）：
- 基座：底板、4 脚（法兰+脚筒）、刻度尺条
- 台身：柜台体（下段+上段两块夹窗）、台面板、下单窗栅栏（5 杆+顶轨）、
  侧窗（腔体+框）、回执管道（管+法兰+接头）、办结台+台章、便签纸叠、笔
- 命令环：中心毂+柱帽、环台盘、内外轨、8 槽托垫、7 号 Link TRB 托（TC 拨杆）、
  enqueue/dequeue 指针牌（活动）
- CRCR 铭牌：基座、牌身、4 位格（RCS/CS/CA/CRR）、CRR 灯罩+灯珠、RCS 旋钮（活动指针）、
  小锁牌（牌+锁梁）
- DCBAA 储物柜：柜体、顶板、6 格（0 号=Scratchpad，2-5 号刻「0」）、柜名牌、「已编址」灯
- 申请单夹：背板、夹子、两张单页（F3 页：控制/槽/EP0；F4 页：控制 A2A3/EP 对）
- 冲压机：底座+立柱+冲头（活动）、托盘料架
- 验卡屏：屏体+内屏（活动卡面：Enable/Address/Configure 三张预刻位域卡）
- 门铃：按钮座+钮帽+铭牌（两行 0/1 语义）
- 旋臂吊（活动）：转柱（静）、臂+吊架+抓头+吊索（逐帧重建）
- 活动件（不在审计内，画在预留槽）：3 张订单托盘、2 指针牌、回执卡、地址牌、夹页

位域卡值（EVIDENCE.md 逐条可溯）：Enable Slot: C@0 / Type=9@15:10 / Slot Type@20:16；
Address Device: Input Context Pointer 63:4（16B 对齐）/ BSR=0@9 / Type=11 / Slot ID@31:24；
Configure Endpoint: DC=0@9 / Type=12 / Slot ID；回执: Type=33 / CC=1@DW2[31:24] / Slot ID@DW3[31:24]。

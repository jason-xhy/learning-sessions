# specs/ —— 规范原文自行下载（版权原因不随包分发）

课程引用的三份规范，请从官方渠道获取后放到本目录。最低要求：把 xHCI 1.2 PDF 命名为 `xhci_1.2_2019.pdf` 放在本目录，课程内链接即可用；USB2/USB3.2 可保持任意目录名（课程以文字引用章节号）。

| 规范 | 官方来源 | 建议文件名 |
|---|---|---|
| xHCI 1.2（645 页，2019） | Intel：intel.com 搜 "xHCI specification"（eXtensible Host Controller Interface for USB Definition） | `xhci_1.2_2019.pdf` |
| USB 2.0 主规范 + ECN 包 | usb.org → Documents 搜 "USB 2.0 specification"（免费下载） | `usb_20.pdf` |
| USB 3.2 Rev 1.1 + ECN 包 | usb.org → Documents 搜 "USB 3.2"（免费下载） | `USB 3.2 Revision 1.1.pdf` |

注意：规范 PDF 版权属 USB-IF / Intel，下载供个人学习使用，请勿再分发。

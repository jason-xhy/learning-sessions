# 学习者指南 · 其他人怎么用这套课程

> 本课程按 teach 工坊模式构建：**知识内容通用，选课路径因人而异**。原作者的课序由他本人的诊断缺口决定；你应当按你自己的诊断结果选课。框架本身就是"先诊断后教学"。

## 两种用法

**① 自学模式（无 AI 助手）**
1. 浏览器打开科目根目录的 `0001-knowledge-map-diagnostic.html`，做 30 题体系诊断（7 领域；即时判分，解析就是微型锚点卡——答错的地方解析会给你规范章节与内核行号）。
2. 拿着分领域得分，对照下面的**路由表**选课。
3. 每课末尾有检索练习自检；测验答案位置已轮换，无规律可背。
4. 深究任何主题：先 grep `规范全文精读摘要库.md`，再读 `specs/` 原文（见 `specs/README.md` 下载指引）。

**② 陪学模式（有 AI 助手，体验完整）**
解压后跑一次 `setup.sh`（随私有仓 learning-sessions-plan（tools/learning-sessions/usb-xhci-learn/，公开仓只含交付物）分发），它做两件事：①把 `TEACHING-PROTOCOL.md`（陪学协议）**幂等合入**你的 `AGENTS.md`（标记块包裹、不覆盖你已有的内容，`AGENTS_FILE=路径` 可指定别的文件）；②从上游开源仓（github.com/mattpocock/skills）拉取 `/teach` 技能装到 `TEACH_SKILLS_DIR`（默认 `~/.zcode/skills`）——**网络不通则自动回退自学模式**，并给出提示。之后对任意 AI 工具说"按 AGENTS.md 当我的老师"（或 ZCode 里键入 `/teach`）即可开始：陪学会**先重新诊断你的基线**、画你的缺口图、再按缺口定制课程——个人文件（MISSION/learning-records）会被按你重置。

## 哪些内容通用、哪些是个人的

- **通用（人人可用）**：lessons/ 的全部知识内容、reference/ 速查卡、assets/ 组件、四份笔记与摘要库、fig0-4、checklists/。
- **个人（自学可忽略；陪学模式会被 agent 按你重置）**：`MISSION.md`（原作者的使命，可当格式样例）、`learning-records/`（原作者的学习基线，不代表你的水平）。

## 维护说明（会话 agent 执行）

新增课程时**必须同步更新本文路由表**（登记在 NOTES.md 待办）；分发打包（`scripts/package-dist.sh`）自动收录本文件。

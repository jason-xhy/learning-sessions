# 湖南省小学三年级 语数外 中文陪学框架（自学包）

面向湖南家庭的三年级（上、下两学期）语文·数学·英语陪学课程：以《义务教育课程标准（2022年版）》第二学段（语文/数学）与一级（英语）为锚，覆盖**三年级学年骨架**——两块能力知道"是什么、什么情况用、怎么自查"，而不是刷题追进度。框架 AI 原生：诊断出缺口后，课程由陪学 AI 按缺口生长。（四年级用配套科目 `hunan-g4-learn`。）

## 快速开始（两条路径）

- **自学模式（无 AI）**：浏览器直接打开根目录的 **`0001-knowledge-map-diagnostic.html`**（手机可用），带孩子做 60 题体系诊断（语文/数学/英语各 20 题，分三部分可分次做，每次 15~20 分钟；即时判分，解析即方法卡）→ 按**分领域得分**对照 `LEARNERS.md` 路由表找补强方向（细节课在 `lessons/`，按缺口生成）→ 每课末尾测验自检。**刚上三上？下学期内容的题答错属正常，不算缺口。**
- **陪学模式（有 AI 助手）**：在科目文件夹里跑 `bash setup.sh`——①把陪学协议幂等合入你的 `AGENTS.md`（不覆盖已有内容）；②从上游拉取开源 `/teach` 技能（网络不通自动回退自学模式）。然后对 AI 工具说"按 AGENTS.md 当我的老师"（ZCode 里 `/teach`），它会先重新诊断孩子的基线、与家长对齐目标、按缺口定制课程——单次 15~25 分钟，遵守双减作业红线，课是跟着孩子的缺口生长的。

## 文件地图

| 路径 | 内容 |
|---|---|
| `0001-knowledge-map-diagnostic.html` | **入门第一课（三年级版）**：语数外三科知识地图 + 60 题体系诊断（12 领域 × 5 题，P1 语文/P2 数学/P3 英语）。单文件自包含，手机浏览器即可作答 |
| `docs/CURRICULUM-FRAMEWORK.md` | **教学框架总设计图（三年级）**：三科能力骨架、三上/三下推进表、诊断→补缺→回测闭环、家庭落地规范、湖南教材口径 |
| `docs/TEACHING-PROTOCOL.md` | AI 陪学协议（setup.sh 合入 AGENTS.md 的正文） |
| `lessons/` | 细节课（按诊断缺口生成后落位于此） |
| `assets/` | 课程共享样式与测验引擎（供细节课链接） |
| `LEARNERS.md` | 学习者指南 + 领域→行动路由表 |
| `scripts/` | 课目自检（check_lessons.py）、答案均衡（quiz_balance.py）、标答导出（quiz_answer_key.py）、分发打包（package-dist.sh）、课件模板（lesson-template.html） |

## 注意

- 本框架所有目标锚定**课标原文**（2022 年版）；教材单元以学校实际用书为准——湖南常见组合：语文统编版、数学人教版为主流、英语湘少版/人教PEP/外研社并存（2024 起新版教材陆续替换，开学翻课本版权页确认一次即可）。
- 陪学遵守**双减**约束：单次 15~25 分钟，书面练习增量每次 ≤2 页；动机安全优先于进度完成。

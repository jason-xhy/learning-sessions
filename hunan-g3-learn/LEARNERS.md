# 学习者指南 · 家长和孩子怎么用这套三年级陪学包

> 本包按 teach 工坊模式构建：**知识内容通用，学习路径因人而异**。孩子的起点不同、教材版本可能不同，所以这里没有固定课序——先做诊断测评，再按孩子的缺口图定制课程。框架本身就是"先诊断后教学"。（四年级配套科目见仓库 `hunan-g4-learn/`。）

## 两种用法

**① 自学模式（可借任意 AI 生成定制课，无需陪学老师）**
1. 家长用手机或电脑打开科目根目录的 `0001-knowledge-map-diagnostic.html`（双击即测，无需安装），带孩子做 **60 题体系诊断**（语文/数学/英语各 20 题，分 P1/P2/P3 三部分，**可分三次做，每次 15~20 分钟**；即时判分，每题解析就是一张"方法卡"）。
2. 三部分答完后，在「测评完成」面板点 **「生成定制课指令包」**：选学期、填教材版本（选填），把指令包整段复制粘贴给任意 AI 助手（豆包/DeepSeek/ChatGPT 均可），它就会生成双击可用的单文件定制补强课——**给孩子用前，把课程代码粘回测评页底部「校验生成的课」机检（查答案位置泄露/图示损坏/断网失效/缺 AI 标识），通过后再抽查 2~3 题答案**；选上学期时下学期题目的错题自动不算缺口。
3. 拿着分领域得分（12 领域各自 x/5），对照下面的**路由表**找补强方向：解析重读 + 框架文档对应章节 + 待建细节课（在 `lessons/`，按缺口生成）。
4. **刚上三年级上学期**：下学期内容（三下列）答错属正常，不算缺口；**三年级下学期**按本表直接判读。
5. 每课末尾有检索练习自检；测验答案位置已轮换，孩子背不到规律。

**② 陪学模式（有 AI 助手，体验完整）**
在科目文件夹里跑一次 `bash setup.sh`，它做两件事：①把 `docs/TEACHING-PROTOCOL.md`（陪学协议）**幂等合入**你的 `AGENTS.md`（标记块包裹、不覆盖你已有的内容，`AGENTS_FILE=路径` 可指定别的文件）；②从上游开源仓（github.com/mattpocock/skills）拉取 `/teach` 技能装到 `TEACH_SKILLS_DIR`（默认 `~/.zcode/skills`）——**网络不通则自动回退自学模式**。之后对 AI 工具说"按 AGENTS.md 当我的老师"（ZCode 里 `/teach`）即可开始：陪学老师会**先重新诊断孩子的基线**、与家长对齐目标（当前学期、教材版本、本学期最想解决的 1~2 件事）写入 `MISSION.md`、画出 12 领域缺口图（`learning-records/`），再按缺口逐节定制课程——单次 15~25 分钟，遵守双减作业红线。

## 领域 → 行动路由表（三年级）

**语文（P1，各 x/5）**

| 答错的领域 | 优先行动 |
|---|---|
| 识字写字（检字法/多音字/形近字/书写） | 课 0001 该领域解析 + 框架 §2 语文① + 待建课「查字典两把钥匙」 |
| 阅读鉴赏（默读/预测/词句/主要内容） | 课 0001 该领域解析 + 框架 §2 语文② + 待建课「预测三步法」 |
| 表达交流（转述/习作起步/修改/标点） | 课 0001 该领域解析 + 框架 §2 语文③ + 待建课「把画面写具体」 |
| 梳理探究（分类/背诵/工具书/形声字） | 课 0001 该领域解析 + 框架 §2 语文④ + 待建课「给字词安家」 |

**数学（P2，各 x/5）**

| 答错的领域 | 优先行动 |
|---|---|
| 数与运算（时分秒/倍/乘除算理/分数/验算） | 课 0001 该领域解析 + 框架 §2 数学① + 待建课「乘除互逆与验算」 |
| 图形几何（周长面积/长正方形/面积单位） | 课 0001 该领域解析 + 框架 §2 数学② + 待建课「周长 vs 面积」 |
| 量与统计（进率/年月日/复式统计表/收集） | 课 0001 该领域解析 + 框架 §2 数学③ + 待建课「单位换算想进率」 |
| 问题解决（审题/画图/检验/归一/搭配） | 课 0001 该领域解析 + 框架 §2 数学④ + 待建课「应用题第一招：圈画与画图」 |

**英语（P3，各 x/5）**

| 答错的领域 | 优先行动 |
|---|---|
| 语音词汇（字母发音/拼读/复数/记词法） | 课 0001 该领域解析 + 框架 §2 英语① + 待建课「拼读开窍」 |
| 句型语法（be 动词/this·that/问答配套/Is this…?） | 课 0001 该领域解析 + 框架 §2 英语② + 待建课「be 动词三兄弟」 |
| 听说交际（课堂指令/问候/致谢告别） | 课 0001 该领域解析 + 框架 §2 英语③ + 待建课「开口三件套」 |
| 读写初步（书写规范/词序/四线三格/图句配对） | 课 0001 该领域解析 + 框架 §2 英语④ + 待建课「四线三格与图句配对」 |

> 标注「待建课」的条目由陪学老师按缺口现场生成（从 `scripts/lesson-template.html` 复制起步）；**课程落成后必须同步更新本表**，把"待建"替换为真实课号。缺口 ≤1 题的领域暂不动——把课时留给真缺口。

## 每月自测：上学期第一个月（month1-selfcheck）

`month1-selfcheck/` 提供**第一个月（9 月）三科自检卷**，与 0001 学年诊断配套（月度小切面对学年骨架），语数外每科三版 markdown（可直接打印）+ 单文件 HTML 直发入口：

- `{科目}-教师版.md`：试卷 + 参考答案与解析 + **双向细目表（评价接口：难度 / 课标锚点 / 大纲匹配，附 JSON 供程序读取）** + 知识体系框架图（mermaid + PNG 双保险）。
- `{科目}-学生版.md`：试卷 + 自评与计分（等级表）+ **短板总结**（按知识点登记表，可整页交给陪学老师）。
- `{科目}-家长版.md`：**进度速览**（4 周速览 + 每个知识点的人话解释）+ 组织自检流程 + 批改答案 + 短板解读与家庭话术。
- `2026-2027上学期第一个月{科目}自测.html`：**单文件直发入口（家庭用这个）**——学生点开直接做（选择/判断点选、填空打字、主观题纸上写后勾"纸上已完成"），交卷批改出成绩单（各知识点得分+最需补清单），截图回传；由 build_html.py 从教师版生成。

用法：**家庭直发用 HTML 入口**（学生点开做，成绩单截图回传；分发命令见私仓 phase0 直发 SOP）；**打印走 md**——一次一科、不连考→ 孩子限时自测、自批 → 家长抽 3 题复核 → 按等级表与短板登记表定位短板 → 把短板交回陪学老师定制补缺小课，或回 0001 诊断对应领域细查。文件结构与机检契约见 `month1-selfcheck/_规范.md`；改动后必跑 `python3 month1-selfcheck/check.py`（学生/家长版由 `build_versions.py` 生成，禁手写）。

## 哪些内容通用、哪些是个人的

- **通用（人人可用）**：0001 诊断、month1-selfcheck/ 月度自测三版、docs/ 两份文档、assets/ 组件、scripts/ 自检与打包脚本、lessons/ 全部知识内容。
- **个人（不入包）**：孩子的 `MISSION.md`、`learning-records/`——陪学模式下由 agent 与家长对齐后新建；换一个孩子，从 0001 诊断重新起步即可。

## 维护说明（会话 agent 执行）

新增课程时**必须同步更新本文路由表**；分发打包（`bash scripts/package-dist.sh`）自动收录本文件。改动 `0001-knowledge-map-diagnostic.html`（题目/引擎/导出指令包/页内校验器）后必跑 `node scripts/test_export.js`（sem 标注 + 指令包结构）与 `node scripts/test_export_dom.js`（导出面板 DOM 全流程），连同 `check_lessons.py`、`test_validator.js`（页内校验器；`~/Documents` 有三家×三科 9 份真实 AI 产出时全量校验，缺失逐份 SKIP）一起 PASS 才算交付。

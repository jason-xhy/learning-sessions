# 湖南省初一（七年级） 家庭自学包

面向湖南初一家庭的分月自我检测与陪学课程：以《义务教育课程标准（2022 年版）》为锚，按"**先自检找短板，再按短板补**"运转。与小学段 `hunan-g3-learn` / `hunan-g4-learn` 同一方法论，覆盖初中七科（语文 / 数学 / 英语 / 历史 / 地理 / 生物 / 道德与法治）。

## 当前内容：上学期第一个月自我检测（month1-selfcheck/）

七科 × 三版本共 21 份 markdown（可打印、可微信直发，无外链、单文件可读）：

| 版本 | 给谁用 | 里面有什么 |
|---|---|---|
| **教师版** | 教师 / 家庭自查主档 | 试卷 + 答案解析 + **评价接口**（双向细目表：每题难度、课标锚点、大纲匹配 + JSON）+ 知识体系框架图（mermaid + PNG） |
| **学生版** | 孩子做题 | 试卷 + 自评计分规则 + **短板总结**（按知识点登记 → 短板清单 → 复测约定） |
| **家长版** | 家长 | **进度速览**（这个月学了什么、人话解释）+ 组织自检步骤 + 批改答案速查 + 短板解读与家庭话术 |

教师版的"教学进度管理、各学生短板评估"两模块按需求暂缓（评价接口即为其预留的数据入口）；教学范围按 2024 秋新版教材 9 月进度核实（湘教/人教/统编对照，以学校实际用书为准），详见 `month1-selfcheck/_规范.md` §6。

## 怎么用（家庭 10 分钟上手）

1. 读该科**家长版**（10 分钟）→ 打印**学生版**；
2. 限时独立完成（一次一科，遵守双减：不连考）；
3. 孩子先自评、家长抽 3 题复核，一起填**短板总结**表；
4. 按短板清单回课本 + 重做错题，7~10 天后只重做错题复测。

改动包内文件后跑 `python3 month1-selfcheck/check.py` 机检（结构 / 分值 / 答案分布 / 三版一致性 / 外链 / 页脚 AI 标识）。

## 注意

- 教材单元以学校实际用书为准（湖南常见：语文/历史/道法统编版、数学湘教版或人教版、英语人教版或仁爱版、地理湘教版或人教版、生物人教版）；
- 陪学遵守**双减**约束：单科限时、一次一科，动机安全优先于进度完成；
- 本包内容以 [MIT](LICENSE) 开源；诊断 HTML 与陪学协议按缺口后续生长（与 g3/g4 同构）。

# 湖南省初一（七年级） 家庭自学包

面向湖南初一家庭的分月自我检测与陪学课程：以《义务教育课程标准（2022 年版）》为锚，按"**先自检找短板，再按短板补**"运转。与小学段 `hunan-g3-learn` / `hunan-g4-learn` 同一方法论，覆盖初中七科（语文 / 数学 / 英语 / 历史 / 地理 / 生物 / 道德与法治）。

## 当前内容：上学期第一个月自我检测（month1-selfcheck/）

**家庭拿 `month1-selfcheck/html/` 下的 21 份自包含 HTML——双击即用、微信可直发**，文件名即用途：

| 文件 | 给谁用 | 里面有什么 |
|---|---|---|
| `2026-2027上学期第一个月{科目}自测.html` | **孩子做题** | 交互卷：点选作答（选择/判断）、限时计时、交卷自动批改；填空与主观题对照参考答案+采分点自评给分；家长可逐题改判；自动生成 等级 + 按知识点汇总 + 短板清单 + **成绩单摘要（截图保存）**；可勾"未讲到，跳过"按已做题换算；可打印 |
| `…自测-家长版.html` | 家长 | 进度速览（人话）+ 组织自检步骤 + 批改答案速查卡 + 短板解读与家庭话术 |
| `…自测-教师版.html` | 教师 / 家庭自查主档 | 试卷 + 逐题解析 + 评价接口（双向细目表 + JSON）+ 知识框架图 |

md 源文件（`{科目}-{教师|学生|家长}版.md`）是内容唯一源，供维护者改题与复核；改 md 后重新生成 HTML（生成与机检工具在私仓 `learning-sessions-plan` 的 `tools/hunan-g7-learn-month1-html/`，见 `_规范.md` §8）。教师版的"教学进度管理、各学生短板评估"两模块按需求暂缓（评价接口即为其预留的数据入口）。

## 怎么用（家庭 10 分钟上手）

1. 孩子点开该科**自测.html**（手机/电脑浏览器均可），限时独立完成，一次一科（双减：不连考）；
2. 交卷批改：选择/判断自动判分，填空/主观对照采分点自评，家长抽 3 题复核、可改判；
3. 看结果区：等级 + 按知识点短板清单，把**成绩单摘要截图保存**（或发给老师/家长）；
4. 按短板清单回课本 + 重做错题，7~10 天后只重做错题复测。

## 微信直发注意（P0）

- 只发 `html/` 下单个文件，文件名即说明，无需解释格式；
- 打开兜底：若点开显示为一堆代码，点右上角「···」→「用其他应用打开」/「在浏览器打开」（苹果手机选 Safari）；
- 进度自动保存在本机浏览器，但清理浏览器数据会丢、换设备不带过去——提示孩子"一次做完再交卷"；
- 全部文件自包含（无外链、无网络依赖），离线可用、可打印。

## 注意

- 教材单元以学校实际用书为准（湖南常见：语文/历史/道法统编版、数学湘教版或人教版、英语人教版或仁爱版、地理湘教版或人教版、生物人教版）；
- 陪学遵守**双减**约束：单科限时、一次一科，动机安全优先于进度完成；
- 本包内容以 [MIT](LICENSE) 开源；诊断 HTML 与陪学协议按缺口后续生长（与 g3/g4 同构）。

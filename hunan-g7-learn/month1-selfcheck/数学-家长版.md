## 一、进度速览（孩子这个月学了什么）

本月数学只学“有理数”前半章：认识负数、把数分类、数轴、相反数、绝对值、比大小、加减法。**乘除法和乘方这个月还没考**，本卷也完全不涉及。

| 周次 | 学的内容 | 白话说明 |
|---|---|---|
| 第 1 周 | 认识负数 | 用正负号记录“意义相反”的量：收入记正、支出记负，水位高记正、低记负 |
| 第 2 周 | 数轴、相反数、绝对值 | 数轴是所有数的“刻度尺”；相反数是只差一个正负号；绝对值是到 0 的距离 |
| 第 3 周 | 数的分类与比大小 | 整数、分数分家；两个负数比大小，绝对值大的反而小 |
| 第 4 周 | 有理数的加减法 | 本月最重的板块，全卷近四成分数在这里 |

**每个知识点一句人话（KP1~KP8）：**

- KP1 负数与相反意义的量：比 0 小的数就是负数；“水位比基准低 0.3 米”记作 -0.3 米，这就是用负数记相反意义的量。
- KP2 有理数分类：把数分成整数和分数两大家族；0 既不是正数也不是负数，但它是整数。
- KP3 数轴：一条带原点、正方向、刻度的直线，每个数在上面都有自己的位置，越靠右的数越大。
- KP4 相反数：只有正负号不同的两个数，比如 +3 和 -3；0 的相反数还是 0。
- KP5 绝对值：数轴上这个数到 0 的距离，永远不小于 0——所以“-3 的绝对值”是 3，不是 -3。
- KP6 大小比较：正数大于 0，0 大于一切负数；两个负数比，绝对值大的反而小，比如 -5 < -3。
- KP7 加减运算：同号相加，符号不变、数字相加；异号相加，符号跟绝对值大的、数字相减；减一个数等于加它的相反数。
- KP8 数形结合与规律探索：画条数轴帮着想数的问题；在一列数里找“每次多几、正负交替”的规律。

**进度差异说明**：个别学校已讲到乘除法，相关题可自行加练，但本卷不涉及乘除与乘方；若学校还没讲到加减法，孩子可暂不做第 16、17、19 题，成绩按已做题换算（已做题得分 ÷ 已做题满分 × 100）。

## 五、常见误区与家庭话术

1. **误区：“-3 的绝对值是 -3。”** 绝对值是“到 0 的距离”，距离没有负的，|-3| = 3。可照说：“你从家走 3 步，不管朝哪个方向，走的距离都是 3 步——绝对值就是这段距离，永远不带负号。”
2. **误区：符号丢错**（-5+3 算成 8，或结果漏写负号）。可照说：“计算只分两步——第一步定符号，第二步算数字。你把这两步写出来，我只检查这两步。” 陪练：每天 5 道加减小题，只看“符号定得对不对”，不追求数量。
3. **误区：“0 不是正数也不是负数，它是不是没家？”** 可照说：“0 是正负的分界线本身，它没有正负，但它属于整数家族，也是有理数。”
4. **误区：“一看就会，一做就废。”** 可照说：“别心算跳步，把每一步写出来——写出来的步骤就是得分点。” 每次只盯错因（错在哪一步、为什么错），不盯分数。
